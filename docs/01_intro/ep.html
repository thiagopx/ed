✊ EP 01: Pedra, papel ou tesoura (PvP)

Entrega: 31 de Agosto

O Cenário: Neste primeiro exercício, você deve implementar a lógica básica do jogo "Jokenpô" para dois jogadores humanos. O programa deve capturar as entradas e determinar o vencedor com base nas regras clássicas.

🎮 Regras do Jogo

Pedra (0)
Ganha de Tesoura
Papel (1)
Ganha de Pedra
Tesoura (2)
Ganha de Papel

📋 Requisitos Técnicos

  • Representação: Utilize obrigatoriamente números inteiros para as jogadas: 0 para Pedra, 1 para Papel e 2 para Tesoura.
  • Fluxo: O programa deve ler primeiro a jogada do Usuário 1 e depois a do Usuário 2.
  • Resultado: Exiba claramente na tela quem venceu a partida ou se houve empate.

💻 Exemplo de Execução

Jogador 1, escolha (0, 1, 2): 0
Jogador 2, escolha (0, 1, 2): 2

Resultado: Usuário 1 vence!
Dica: Pense em como os operadores lógicos (&&, ||) podem simplificar suas estruturas de decisão if/else.
