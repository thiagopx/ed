Operadores e E/S

Nem toda divisão sobra decimais

O tipo dos operandos decide se o resultado trunca ou não.

7 / 2

Os dois operandos são int — divisão inteira, trunca a parte decimal.

3

7.0 / 2

Pelo menos um operando é ponto flutuante — o resultado guarda casas decimais.

3.5

Operadores e E/S

++x e x++ não são a mesma coisa

A diferença aparece quando o operador está dentro de uma expressão maior.

x++ (pós-fixado)

A expressão usa o valor atual de x — o incremento acontece depois.

usa 5, x vira 6

++x (pré-fixado)

x é incrementado primeiro — a expressão já usa o novo valor.

x vira 6, usa 6

Decisões

C não tem um tipo booleano

Qualquer expressão numérica pode ser usada como condição de um if.

0

Tratado como falso — o bloco do if não executa.

if (0) → não executa

≠ 0

Qualquer valor diferente de zero é tratado como verdadeiro.

if (5) → executa

Decisões

switch testa em cascata, até bater

Sem break, a execução "cai" para o case seguinte (fall-through).

case '+'
case '-'
case '*'
case '/' ← bate aqui, executa até o break
default só roda se nenhum case bater
