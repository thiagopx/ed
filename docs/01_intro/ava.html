🧪 Desafio Prático de Compilação

Compile seu programa no terminal utilizando as duas abordagens a seguir:

1. Compilação direta: 
gcc main.c -o <nome_do_programa>
2. Compilação preservando arquivos intermediários: 
gcc --save-temps main.c -o <nome_do_programa>

🧐 Verifique: Quais novos arquivos foram gerados no seu diretório (.i, .s, .o)? Observou alguma diferença no processo de compilação?
