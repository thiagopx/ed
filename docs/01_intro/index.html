Introdução à linguagem C

Primeiros programas em C

Estas são as notas da primeira aula: como um programa em C nasce e roda, os tipos de dado e operadores que ele manipula, como ele conversa com quem o usa, e como ele toma decisões. Os exemplos interativos logo abaixo colocam parte dessa teoria em prática, passo a passo.

Introdução à programação em C

Ciclo de desenvolvimento

Escrever um programa em C passa por três fases, que se repetem em ciclo até o programa funcionar corretamente: primeiro o código é digitado num editor de texto; depois o compilador traduz esse código-fonte para um programa executável, apontando um erro de compilação sempre que a sintaxe está incorreta; por fim o programa executável roda e sua saída é conferida contra o resultado esperado — um erro de execução (o programa compila e roda, mas produz um resultado errado) manda o programador de volta ao editor para revisar a lógica, assim como um erro de compilação manda de volta para corrigir a sintaxe.

Nos bastidores, a compilação em si tem sub-etapas: o pré-processamento resolve diretivas como #include e #define; a compilação propriamente dita traduz o código-fonte para código objeto; e a linkagem junta esse código objeto com as bibliotecas usadas (como a stdio), produzindo o executável final. Compilar com gcc --save-temps (veja o desafio prático deste módulo) deixa os arquivos intermediários de cada etapa visíveis no diretório. 

$ gcc --save-temps main.c -o program
$ ls
main.c  program  program-main.i  program-main.o  program-main.s

Cada arquivo é uma tradução do anterior: program-main.i é o código já pré-processado (o conteúdo de stdio.h expandido acima do seu código, que continua lá intacto), program-main.s é o mesmo programa em assembly, e program-main.o e program já são binários — não há mais texto legível neles.

Verdadeiro ou Falso

Um erro de execução (o programa roda, mas produz um resultado errado) é sinalizado pelo compilador da mesma forma que um erro de sintaxe.

  • VVerdadeiro
  • FFalso

Certo, é falso. O compilador só detecta erros de sintaxe (erros de compilação); um erro de execução passa despercebido por ele — só aparece quando se compara a saída do programa com o resultado esperado.

Não é isso. O compilador não tem como saber se a lógica do programa está certa — ele só verifica a sintaxe. Um erro de execução (resultado errado, mas sem falha de compilação) só é percebido comparando a saída do programa com o que se esperava.

Programando em C: estrutura básica de um programa

Todo programa em C segue o mesmo esqueleto, visível no exemplo Primeiro programa: a diretiva #include traz as declarações de uma biblioteca (aqui, stdio.h, para entrada e saída); a função main() é o ponto de entrada obrigatório — é dela que a execução começa; o corpo de main() é delimitado por chaves { } e contém uma sequência de declarações e comandos executados em ordem, de cima para baixo; e o comando return encerra a função, devolvendo um código de status ao sistema operacional (0 indica sucesso). Comentários (/* ... */, ou // até o fim da linha) documentam o código sem afetar a compilação — o compilador simplesmente os ignora.

Ao lado do #include, a outra diretiva de pré-processador comum é o #define, que cria um apelido de texto para um valor: antes de o código ser traduzido, toda ocorrência do apelido é substituída pelo valor correspondente. É a maneira usual de dar nome a uma constante, em vez de espalhar o número solto pelo programa. 

#define IDADE_ADULTA 18

int limite = IDADE_ADULTA;  /* vira "int limite = 18;" antes de compilar */
Verdadeiro ou Falso

Comentários (/* ... */ ou //) podem ser removidos do código-fonte sem alterar em nada o comportamento do programa compilado.

  • VVerdadeiro
  • FFalso

Certo! Comentários são pura documentação, ignorados pelo compilador — removê-los do código-fonte não muda em nada o programa compilado, só a legibilidade para quem lê o código.

É verdadeiro, sim. Comentários não afetam a compilação nem a execução — são só documentação para quem lê o código; removê-los do fonte não muda o comportamento do programa.

Variáveis e operadores

Variáveis

Uma variável é um espaço nomeado na memória que guarda um valor de um tipo específico — e que pode mudar ao longo da execução do programa.

Verdadeiro ou Falso

Se um programa executa idade = 20; e, mais adiante, idade = 21;, a segunda atribuição é inválida, porque idade já tinha um valor.

  • VVerdadeiro
  • FFalso

Certo, é falso. Reatribuir um novo valor a uma variável que já tinha um valor é exatamente o que uma variável permite — é isso que a diferencia de uma constante; idade = 21; é perfeitamente válida e simplesmente substitui o valor anterior.

Não é isso. Não há nada de inválido — uma variável pode receber um novo valor quantas vezes o programa precisar; idade = 21; simplesmente substitui os 20 anteriores.

Tipos básicos

O C define cinco tipos de dado primitivos — char, int, float, double e void —, cada um ocupando um número fixo de bytes na memória (que pode variar entre plataformas). char guarda um caractere (ou um pequeno inteiro), int um número inteiro, float e double números de ponto flutuante (double com mais precisão), e void representa "nenhum tipo" — usado, por exemplo, para indicar que uma função não retorna valor. Os modificadores signed, unsigned, short e long ajustam a faixa de valores representável por um tipo — um unsigned int, por exemplo, abre mão de representar negativos para dobrar o maior valor positivo possível.

Verdadeiro ou Falso

unsigned int consegue representar valores negativos, além de todos os valores positivos que um int comum representa.

  • VVerdadeiro
  • FFalso

Certo, é falso. É o contrário: unsigned abre mão de representar valores negativos justamente para dobrar o maior valor positivo representável, comparado a um int comum (signed).

Não é isso. unsigned troca a capacidade de representar negativos por uma faixa maior de positivos — não representa os dois ao mesmo tempo.

Declaração de variáveis

Toda variável precisa ser declarada antes de usada — a forma geral é tipo nome;, como em int age; no exemplo Primeiro programa. É possível declarar várias variáveis do mesmo tipo numa linha só, separadas por vírgula (float base, altura;), e também inicializar no mesmo passo da declaração (int contador = 0;).

Verdadeiro ou Falso

Em C, é possível declarar duas variáveis de tipos diferentes (por exemplo, int e float) numa única instrução, separadas por vírgula.

  • VVerdadeiro
  • FFalso

Certo, é falso. A declaração com vírgula (tipo nome1, nome2;) só funciona para variáveis do mesmo tipo — tipos diferentes exigem instruções de declaração separadas, cada uma com seu próprio tipo.

Não é isso. A vírgula só agrupa variáveis do mesmo tipo numa linha; tipos diferentes precisam de uma instrução de declaração para cada um.

Valores constantes

Constantes são valores fixos escritos diretamente no código — 42 e -7 são constantes inteiras, 3.14 uma constante de ponto flutuante, 'a' uma constante de caractere (entre aspas simples) e "Ola" uma constante string (entre aspas duplas, e sempre um vetor de caracteres terminado em '\0'). O C também aceita constantes hexadecimais, prefixadas por 0x (0x1F), e octais, prefixadas por um zero (013).

Verdadeiro ou Falso

Em C, 'a' (aspas simples) e "a" (aspas duplas) representam o mesmo tipo de constante, só com notações diferentes.

  • VVerdadeiro
  • FFalso

Certo, é falso. 'a' é uma constante de caractere, um único valor; "a" é uma constante string, um vetor de caracteres terminado em '\0' — são tipos diferentes, não só notações do mesmo valor.

Não é isso. São tipos diferentes: 'a' (aspas simples) é um caractere só; "a" (aspas duplas) é uma string, um vetor terminado em '\0'.

Variáveis com valores indefinidos

Ao contrário do que se poderia esperar, o C não inicializa automaticamente uma variável recém-declarada com zero: seu valor inicial é indefinido — o que estiver, por acaso, naquele endereço de memória. É o caso de age no exemplo Primeiro programa entre a declaração (int age;) e a leitura pelo scanf: usar seu valor nesse intervalo leria "lixo de memória". Por isso a boa prática é nunca presumir um valor inicial e sempre inicializar explicitamente uma variável antes de lê-la. O exemplo Conversão e variável indefinida imprime esse lixo de propósito, para tornar o problema visível — e mostra um bônus: o próprio compilador (gcc -Wall) já avisa sobre isso com um -Wuninitialized antes mesmo do programa rodar, o que ajuda a pegar esse tipo de erro cedo.

Verdadeiro ou Falso

Em C, uma variável recém-declarada, sem inicialização explícita, sempre começa automaticamente com o valor zero.

  • VVerdadeiro
  • FFalso

Certo, é falso. Ao contrário do que se poderia esperar, o C não zera automaticamente uma variável recém-declarada — seu valor inicial é indefinido, o que estiver por acaso naquele endereço de memória.

Não é isso. Não há zeragem automática — o valor inicial de uma variável não inicializada é indefinido (lixo de memória), por isso a boa prática é sempre inicializar antes de usar.

Operadores

Operadores combinam e transformam os valores guardados nas variáveis.

Verdadeiro ou Falso

Um operador em C só pode combinar duas variáveis entre si, nunca uma variável com uma constante.

  • VVerdadeiro
  • FFalso

Certo, é falso. Um operador combina valores de um modo geral — variável com variável, variável com constante (como em x + 5), ou até duas constantes — não só variável com variável.

Não é isso. Operadores combinam valores quaisquer, incluindo variável com constante (x + 5, por exemplo) — não é uma exigência ter duas variáveis.

Operadores aritméticos

Os operadores +, -, *, / e % realizam as operações aritméticas básicas — soma, subtração, multiplicação, divisão e resto da divisão inteira, respectivamente. O exemplo Fahrenheit para Celsius usa vários deles na mesma expressão: celsius = (fahrenheit - 32) * 5 / 9;. Um detalhe importante: quando os dois operandos de / são inteiros, o resultado é uma divisão inteira, truncada (7 / 2 vale 3, não 3.5) — para obter o resultado real, pelo menos um dos operandos precisa ser de ponto flutuante.

Verdadeiro ou Falso

Numa expressão como soma / 2.0, mesmo que soma seja do tipo int, o resultado da divisão terá casas decimais.

  • VVerdadeiro
  • FFalso

Certo! Basta que um dos operandos seja de ponto flutuante para evitar a divisão inteira — como 2.0 já é float, soma / 2.0 produz um resultado com casas decimais, mesmo com soma sendo int.

É verdadeiro, sim. Já vale ter só um operando de ponto flutuante para evitar a divisão inteira — como 2.0 é float, soma / 2.0 produz um resultado com casas decimais, mesmo com soma sendo int.

Operadores de atribuição

O operador = atribui o valor da direita à variável da esquerda (x = 5;). O C também tem operadores de atribuição compostos, que combinam uma operação com a atribuição numa forma mais curta — x += 3; equivale a x = x + 3;, e o mesmo padrão vale para -=, *=, /= e %=.

Verdadeiro ou Falso

Depois de rodar int x = 10; x /= 4;, o valor de x é 2.5.

  • VVerdadeiro
  • FFalso

Certo, é falso. x /= 4 equivale a x = x / 4; como x é int, a divisão 10 / 4 é inteira e trunca para 2 — x fica com 2, não 2.5 (para ter casas decimais, x precisaria ser float ou double).

Não é isso. x /= 4 equivale a x = x / 4 — com x inteiro, essa divisão é inteira e trunca: 10 / 4 vale 2, não 2.5.

Operadores de incremento e decremento

++ e -- incrementam ou decrementam uma variável em 1, e podem ser usados antes (pré-fixado, ++x) ou depois (pós-fixado, x++) da variável — a diferença aparece quando o operador é usado dentro de uma expressão maior: no pré-fixado, a variável é incrementada primeiro, e o novo valor é o que entra na expressão; no pós-fixado, o valor atual entra na expressão, e só depois a variável é incrementada. 

int x = 5;
int y = x++;   /* y recebe 5, x vira 6 */
int z = ++x;   /* x vira 7, z recebe 7 */

Só é possível aplicar ++/-- diretamente a uma variável, nunca a uma expressão como (a + 1)++. O exemplo Incremento e decremento isola cada uma das quatro formas (x++, ++x, y--, --y) em sua própria instrução — misturar, por exemplo, x e x++ no mesmo printf é um erro comum que leva a um comportamento não bem definido pela linguagem.

Verdadeiro ou Falso

Se x valer 5, a expressão y = ++x; deixa tanto x quanto y com o valor 6.

  • VVerdadeiro
  • FFalso

Certo! No pré-fixado (++x), x é incrementado primeiro (para 6), e esse novo valor de x é o que entra na expressão — por isso y também recebe 6.

É verdadeiro, sim. No pré-fixado (++x), x é incrementado primeiro (para 6), e esse novo valor entra na expressão — então y recebe 6 também, não um valor diferente de x.

Operadores relacionais e lógicos

Os operadores relacionais (>, >=, <, <=, ==, !=) comparam dois valores e retornam verdadeiro (1) ou falso (0) — C não tem um tipo booleano dedicado, então esse resultado é um int comum, como qualquer outro. É assim que o exemplo Fahrenheit para Celsius decide se celsius < 0. Os operadores lógicos combinam expressões booleanas: && (E) só é verdadeiro se ambos os lados forem verdadeiros, || (OU) é verdadeiro se pelo menos um lado for, e ! (NÃO) inverte um valor lógico. 

if (a && funcao_cara())  /* se a for falso, funcao_cara() nunca é chamada */

Expressões conectadas por && ou || são avaliadas da esquerda para a direita, e a avaliação para assim que o resultado já está decidido — chamado de curto-circuito: em a && b, se a já for falso, b nem chega a ser avaliado. O exemplo Operadores lógicos e ternário combina os três operadores lógicos para decidir a elegibilidade a um benefício a partir da idade e da renda.

Verdadeiro ou Falso

Na expressão a || b, se a for verdadeiro, C ainda assim avalia b antes de decidir o resultado da expressão.

  • VVerdadeiro
  • FFalso

Certo, é falso. O curto-circuito vale para os dois operadores: em a || b, se a já for verdadeiro, o resultado já está decidido (verdadeiro), então b nem chega a ser avaliado — o mesmo princípio de a && b, só que no lado oposto.

Não é isso. Assim como em a && b, a || b também usa curto-circuito: se a já for verdadeiro, o resultado da expressão já está decidido, e b nem chega a ser avaliado.

Operador sizeof

sizeof consulta, em tempo de compilação, quantos bytes um tipo ou uma variável ocupa na memória — é exatamente o que o exemplo Tipos de dados usa para revelar o tamanho de cada tipo primitivo (sizeof(int), sizeof(double) etc.) na plataforma em que o programa está rodando.

Verdadeiro ou Falso

sizeof pode devolver valores diferentes para o mesmo tipo (como int), dependendo da plataforma em que o programa é compilado.

  • VVerdadeiro
  • FFalso

Certo! O tamanho de um tipo primitivo pode variar entre plataformas — por isso sizeof(int) não tem um valor universal fixo; é assim que o exemplo Tipos de dados descobre, na prática, quanto cada tipo ocupa na máquina onde o programa está rodando.

É verdadeiro, sim. sizeof(int) pode, sim, variar entre plataformas — o tamanho de um tipo primitivo não é universal; é por isso que sizeof existe, para consultar o valor real na plataforma atual.

Conversão de tipo

Quando uma expressão mistura tipos diferentes, o C converte automaticamente os valores para um tipo comum antes de operar (conversão implícita) — é por isso que, no exemplo Calculadora, ler os operandos como double garante uma divisão com casas decimais, mesmo que o usuário digite números inteiros. Também é possível forçar uma conversão explicitamente com um modelador (cast): (float)a / b converte a para float antes da divisão, garantindo um resultado com casas decimais mesmo que a e b sejam int. 

int a = 7, b = 2;
float r1 = a / b;          /* 3.0 — divisão inteira truncada, só depois virou float */
float r2 = (float)a / b;   /* 3.5 — cast antes da divisão */

O exemplo Conversão e variável indefinida deixa a pegadinha lado a lado: uma divisão entre dois int trunca o resultado antes mesmo de ser guardada numa variável float, e só o cast aplicado a um operando, antes da divisão acontecer, preserva as casas decimais.

Verdadeiro ou Falso

Na expressão (float)a / b, mesmo que b continue sendo int, a divisão inteira nunca chega a acontecer, porque um dos operandos (a, já convertido) é float.

  • VVerdadeiro
  • FFalso

Certo! Basta um operando de ponto flutuante para a divisão deixar de ser inteira — como o cast converte a para float antes da divisão, b continuar int não importa: o resultado já sai com casas decimais.

É verdadeiro, sim. Um único operando de ponto flutuante já evita a divisão inteira — como a virou float pelo cast, a divisão não é mais entre dois inteiros, mesmo que b continue int.

Entrada e saída básicas

Para interagir com quem usa o programa, o C conta com duas funções da biblioteca padrão declaradas em stdio.h.

Verdadeiro ou Falso

As funções printf e scanf fazem parte da linguagem C em si — nenhuma diretiva #include é necessária para usá-las.

  • VVerdadeiro
  • FFalso

Certo, é falso. printf e scanf não são parte do núcleo da linguagem — são funções da biblioteca padrão, declaradas em stdio.h; sem o #include <stdio.h>, o compilador não conhece seus protótipos.

Não é isso. São funções da biblioteca padrão, não da linguagem em si — declaradas em stdio.h, exigem o #include correspondente.

Função printf

printf formata e imprime valores na tela, usando especificadores de formato que indicam o tipo e a formatação de cada valor — %d para inteiros, %f para ponto flutuante, %c para caracteres, %s para strings. Cada % no texto de formato é um espaço reservado, preenchido pelo valor correspondente na mesma ordem em que os valores aparecem depois da vírgula. 

int idade = 20;
float altura = 1.75;

printf("%d anos, %f m\n", idade, altura);
20 anos, 1.750000 m

Além do tipo, o especificador controla a largura mínima do campo e, para pontos flutuantes, o número de casas decimais — como em %7.2f.

Verdadeiro ou Falso

O especificador %7.2f imprime um valor de ponto flutuante usando exatamente 7 casas decimais.

  • VVerdadeiro
  • FFalso

Certo, é falso. Em %7.2f, o 7 é a largura total do campo (quantas posições reservar ao todo), e o 2 depois do ponto define as casas decimais — não são 7 casas decimais, são 7 posições no total, incluindo sinal, dígitos inteiros, ponto e as 2 decimais.

Não é isso. O 7 é a largura total do campo, não o número de casas decimais — quem define as casas decimais é o número depois do ponto (2, neste caso).

Função scanf

scanf lê a entrada digitada pelo usuário e guarda o valor lido dentro de uma variável — mas, diferente de printf, scanf sempre precisa do endereço da variável, não do seu valor, por isso é quase sempre chamado com o operador & antes do nome da variável (scanf("%d", &idade);). Um cuidado comum ao misturar leituras: o exemplo Calculadora lê o operador com scanf(" %c", &operator) — o espaço antes de %c descarta qualquer espaço em branco ou quebra de linha deixada no buffer pela leitura anterior.

Esse endereço passado ao scanf é, na prática, um ponteiro — um tipo com regras próprias, estudado mais adiante no curso. Por ora basta reter que é o & que permite ao scanf escrever o valor lido dentro da variável.

Verdadeiro ou Falso

Assim como printf, scanf recebe o valor da variável diretamente, sem precisar do operador &.

  • VVerdadeiro
  • FFalso

Certo, é falso. Ao contrário de printf, scanf sempre precisa do endereço da variável, não do seu valor — por isso é quase sempre chamado com & antes do nome da variável, como em scanf("%d", &idade).

Não é isso. scanf precisa do endereço da variável (por isso o & antes do nome), justamente para poder escrever o valor lido dentro dela — diferente de printf, que só lê o valor.

Condicionais

Comando if

O comando if executa um bloco de comandos só quando uma condição é verdadeira, e o else, opcional, executa um bloco alternativo quando ela é falsa — é assim que o exemplo Fahrenheit para Celsius decide entre "congelando" e "não congelando".

Verdadeiro ou Falso

A cláusula else é obrigatória sempre que se usa um if.

  • VVerdadeiro
  • FFalso

Certo, é falso. O else é opcional — um if sozinho, sem else, é perfeitamente válido; o else só entra quando existe mesmo um bloco alternativo para o caso da condição ser falsa.

Não é isso. else é opcional; um if sem else simplesmente não faz nada quando a condição é falsa.

Expressões booleanas

O C não tem um tipo booleano dedicado: qualquer expressão numérica pode ser usada como condição — zero é considerado falso, e qualquer valor diferente de zero é considerado verdadeiro. É por isso que if (x) e if (x != 0) são equivalentes, assim como if (!x) e if (x == 0).

Verdadeiro ou Falso

Em C, if (x) e if (x == 1) sempre produzem o mesmo resultado, para qualquer valor de x.

  • VVerdadeiro
  • FFalso

Certo, é falso. if (x) é verdadeiro para qualquer valor diferente de zero (equivale a if (x != 0), não a if (x == 1)) — se x valer 5, por exemplo, if (x) é verdadeiro, mas if (x == 1) é falso.

Não é isso. if (x) equivale a if (x != 0), não a if (x == 1) — um valor como 5 faz if (x) ser verdadeiro, mas if (x == 1) seria falso.

Blocos de comandos

Quando um if precisa executar mais de um comando, os comandos são agrupados entre chaves { }, formando um bloco. Se o corpo do if tiver um único comando, as chaves são opcionais — mas usá-las mesmo assim é uma prática recomendada, porque evita um erro comum: adicionar uma segunda linha ao "corpo" do if sem perceber que, sem chaves, ela na verdade já está fora dele.

Verdadeiro ou Falso

Quando o corpo de um if tem um único comando, as chaves são opcionais e nunca causam confusão, então dispensá-las é sempre uma boa prática.

  • VVerdadeiro
  • FFalso

Certo, é falso. É o oposto: mesmo quando as chaves são opcionais, usá-las é a prática recomendada — sem elas, é fácil adicionar sem perceber uma segunda linha que parece fazer parte do if, mas na verdade já está fora dele.

Não é isso. É o oposto — mesmo opcionais, usar as chaves é a prática recomendada, justamente para evitar o erro comum de uma linha extra parecer parte do if sem estar.

Operador condicional

O operador ternário ?: é uma forma compacta de escrever um if-else que só decide qual de dois valores usar: condição ? valor_se_verdadeiro : valor_se_falso. Por exemplo, int maior = (a > b) ? a : b; guarda em maior o maior valor entre a e b, substituindo um if-else de quatro linhas por uma única expressão. É possível também encadear ternários para decidir entre mais de duas opções — o exemplo Operadores lógicos e ternário (visto na seção de Operadores) usa um ternário dentro de outro para classificar uma idade em três faixas.

Verdadeiro ou Falso

O operador ternário condição ? valor_se_verdadeiro : valor_se_falso substitui qualquer tipo de comando if-else, não só os que decidem entre dois valores.

  • VVerdadeiro
  • FFalso

Certo, é falso. O ternário só serve para escolher entre dois valores dentro de uma expressão — um if-else que executa comandos além de atribuir um valor (como imprimir algo ou chamar uma função com efeito colateral) não pode, em geral, virar um ternário.

Não é isso. O ternário só substitui um if-else que decide entre dois valores; um if-else que executa comandos (não só atribui um valor) não pode, em geral, virar um ternário.

Seleção

O comando switch testa uma única variável (ou expressão) contra uma lista de valores constantes, executando o case correspondente — uma alternativa mais legível a uma longa cadeia de if-else-if quando há muitos valores possíveis para testar, como faz o exemplo Calculadora ao escolher a operação aritmética a partir do caractere digitado. Cada case termina, tipicamente, com um break, que interrompe o switch; sem ele, a execução "cai" para o case seguinte (fall-through) mesmo que sua condição não bata — um comportamento às vezes proposital, mas fonte comum de bugs quando esquecido. A cláusula default, opcional, é executada quando nenhum case corresponde ao valor testado.

Verdadeiro ou Falso

Sem um break no final do case, o switch para automaticamente ali, sem executar o case seguinte.

  • VVerdadeiro
  • FFalso

Certo, é falso. É o contrário: sem break, a execução não para — ela "cai" para o case seguinte (fall-through) mesmo que a condição dele não bata, um comportamento às vezes proposital, mas fonte comum de bugs quando esquecido.

Não é isso. Sem break, a execução continua para o case seguinte (fall-through), mesmo que sua condição não bata — não para automaticamente.

Fahrenheit para Celsius

ver no GitHub ↗ 
#include <stdio.h>

int main()
{
    float fahrenheit, celsius;

    // Input temperature in Fahrenheit
    printf("Enter temperature in Fahrenheit: ");
    scanf("%f", &fahrenheit);

    // Convert Fahrenheit to Celsius
    celsius = (fahrenheit - 32) * 5 / 9;

    // Output temperature in Celsius
    printf("Temperature in Celsius: %.2f\n", celsius);

    // Check if temperature is below freezing
    if (celsius < 0)
        printf("It's freezing outside!\n");
    else
        printf("It's not freezing outside.\n");

    return 0;
}

Como funciona a conversão

A fórmula (fahrenheit - 32) * 5 / 9 aplica a conversão padrão de Fahrenheit para Celsius. Depois de calcular celsius, um único if/else decide qual mensagem imprimir, comparando celsius com 0 — o ponto de congelamento da água.

Repare que não há parênteses envolvendo 5 / 9. Se o código fosse escrito como (fahrenheit - 32) * (5 / 9), o resultado seria sempre 0: como 5 e 9 são inteiros, 5 / 9 seria uma divisão inteira que trunca para 0 antes de multiplicar por fahrenheit - 32. Sem os parênteses extras, * 5 primeiro promove a conta para float (porque fahrenheit - 32 já é float), e só depois a divisão por 9 acontece em ponto flutuante.

  • AO programa não compilaria, pois scanf("%f", ...) exige uma variável float.
  • BNada mudaria — a fórmula continuaria produzindo o mesmo resultado.
  • CA divisão final por 9 passaria a truncar (divisão inteira), mudando o resultado da conversão em boa parte dos casos.
  • DO programa passaria a imprimir sempre "It's freezing outside!", independente da temperatura.

Certo! Com int, (fahrenheit - 32) * 5 continuaria um valor inteiro, mas a divisão final por 9 se tornaria uma divisão inteira, truncando o resultado — a conversão deixaria de ser precisa.

Não é isso. Com int, a divisão final por 9 se tornaria uma divisão inteira (truncada), alterando o resultado da fórmula em boa parte dos casos — o scanf("%f", ...) continuaria compilando, só leria errado.

Calculadora

#include <stdio.h>

int main()
{
    double num1, num2, result;
    char operator;

    printf("Enter first number: ");
    scanf("%lf", &num1);

    printf("Enter operator (+, -, *, /): ");
    scanf(" %c", &operator); // Notice the space before %c to consume the newline character.

    printf("Enter second number: ");
    scanf("%lf", &num2);

    switch (operator)
    {
    case '+':
        result = num1 + num2;
        break;
    case '-':
        result = num1 - num2;
        break;
    case '*':
        result = num1 * num2;
        break;
    case '/':
        if (num2 != 0)
            result = num1 / num2;
        else
        {
            printf("Error: Division by zero\n");
            return 1; // Exit with an error code
        }
        break;
    default:
        printf("Error: Invalid operator\n");
        return 1; // Exit with an error code
    }

    printf("Result: %lf\n", result);

    return 0; // Exit successfully
}

Como funciona o switch

switch (operator) compara operator com cada case até encontrar um que bata; a partir daí executa até achar um break. Sem o break, a execução "cairia" para o próximo case (fall-through) — por isso todo case aqui termina com break, exceto os que já terminam com return.

Incremento e decremento

ver no GitHub ↗ 
#include <stdio.h>

int main()
{
    int x = 5;
    printf("x = %d\n", x);

    int resultado_pos = x++;
    printf("x++ devolveu %d (valor de x antes do incremento)\n", resultado_pos);
    printf("agora x = %d\n", x);

    int resultado_pre = ++x;
    printf("++x devolveu %d (valor de x depois do incremento)\n", resultado_pre);
    printf("agora x = %d\n", x);

    int y = 10;
    printf("\ny = %d\n", y);

    int resultado_pos_y = y--;
    printf("y-- devolveu %d (valor de y antes do decremento)\n", resultado_pos_y);
    printf("agora y = %d\n", y);

    int resultado_pre_y = --y;
    printf("--y devolveu %d (valor de y depois do decremento)\n", resultado_pre_y);
    printf("agora y = %d\n", y);

    return 0;
}

Como funciona pré e pós-incremento

Cada uma das quatro formas (x++, ++x, y--, --y) é isolada em sua própria instrução, guardando o valor devolvido numa variável separada (resultado_pos, resultado_pre etc.) antes de imprimir — isso evita misturar, por exemplo, x e x++ no mesmo printf, o que a linguagem C não define bem o resultado. No pós-fixado (x++), a expressão usa o valor atual de x, e só depois x é incrementado. No pré-fixado (++x), x é incrementado primeiro, e a expressão já usa o novo valor.

Operadores lógicos e ternário

ver no GitHub ↗ 
#include <stdio.h>

int main()
{
    int idade;
    float renda_mensal;

    printf("Digite a idade: ");
    scanf("%d", &idade);
    printf("Digite a renda mensal: ");
    scanf("%f", &renda_mensal);

    int maior_de_idade = idade >= 18;
    int renda_baixa = renda_mensal < 2000.0;

    /* Operadores logicos: && (E), || (OU), ! (negacao) */
    int elegivel = maior_de_idade && renda_baixa;
    int precisa_documento_extra = !maior_de_idade || renda_mensal > 5000.0;

    printf("\nElegivel para o beneficio: %s\n", elegivel ? "sim" : "nao");
    printf("Precisa de documento extra: %s\n", precisa_documento_extra ? "sim" : "nao");

    /* Operador condicional (ternario): teste ? valor_se_verdadeiro : valor_se_falso */
    const char *faixa = idade < 18 ? "menor de idade" : (idade < 60 ? "adulto" : "idoso");
    printf("Faixa etaria: %s\n", faixa);

    return 0;
}

Como funcionam os operadores lógicos e o ternário

&& (E) só resulta em verdadeiro se os dois lados forem verdadeiros; || (OU) resulta em verdadeiro se pelo menos um lado for; ! (NÃO) inverte um valor lógico. As duas primeiras chamadas de printf usam o operador ternário (?:) só para escolher a string a imprimir ("sim" ou "nao"); a última usa um ternário aninhado — o resultado do primeiro ?: é, ele mesmo, outro ?: — para escolher entre três faixas etárias em vez de só duas.

Conversão e variável indefinida

ver no GitHub ↗ 
#include <stdio.h>

int main()
{
    /* ---- Parte 1: conversao de tipo ---- */
    int total_pontos = 17;
    int quantidade_provas = 5;

    /* Divisao entre dois inteiros trunca o resultado */
    float media_errada = total_pontos / quantidade_provas;
    printf("Media (sem conversao): %.2f\n", media_errada);

    /* Convertendo um operando para float antes da divisao (cast explicito) */
    float media_certa = (float) total_pontos / quantidade_provas;
    printf("Media (com conversao explicita): %.2f\n", media_certa);

    /* ---- Parte 2: variavel com valor indefinido ---- */
    int nao_inicializada;
    printf("\nValor de uma variavel nao inicializada: %d\n", nao_inicializada);
    printf("(Esse numero nao tem significado - e o que sobrou na memoria antes de ser usada. Nunca leia uma variavel antes de dar um valor a ela.)\n");

    return 0;
}

Como funcionam a conversão e a variável indefinida

A primeira metade do programa mostra a mesma divisão calculada de duas formas: em media_errada, os dois operandos (total_pontos e quantidade_provas) são int, então a divisão já acontece truncada — o resultado (inteiro) só é convertido para float depois de pronto, ao ser guardado. Em media_certa, o cast (float) converte total_pontos para float antes da divisão acontecer, o que já basta para toda a conta ser feita em ponto flutuante. A segunda metade declara nao_inicializada e a lê sem nunca ter atribuído um valor a ela — o C não zera variáveis automaticamente, então o que é lido é lixo de memória.

Para lembrar. Todo programa em C tem a mesma anatomia — includes, main, declarações, comandos e return. Variáveis precisam ser declaradas com um tipo antes de usadas, e esse tipo determina quantos bytes ela ocupa (sizeof) e como as operações sobre ela se comportam (divisão inteira vs. divisão em ponto flutuante, fall-through em switch, etc.).
