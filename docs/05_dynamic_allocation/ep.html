🎒 EP 05: Fusão de Esquadrões

Entrega: 16 de Setembro

O Cenário: Dois esquadrões de aventureiros exploraram, separadamente, a mesma masmorra e coletaram itens — cada item identificado por um código inteiro. Ao se encontrarem na saída, os dois esquadrões decidem juntar tudo o que encontraram num único inventário, sem duplicar nenhum item que os dois tenham coletado por acaso. Você foi chamado para escrever o programa que calcula esse inventário combinado. Como não se sabe de antemão quantos itens cada esquadrão vai coletar numa exploração, os vetores de itens não podem ter tamanho fixo — precisam ser alocados dinamicamente, do tamanho exato que cada exploração exigir.

📋 Requisitos Técnicos

  • Entrada dinâmica: leia a quantidade de itens do Esquadrão A e aloque um vetor de inteiros desse tamanho com malloc (nunca um vetor estático de tamanho fixo); repita o processo para o Esquadrão B, com um vetor independente.
  • Função de fusão: implemente uma função dedicada que recebe os dois vetores de itens e seus respectivos tamanhos, e aloca e devolve (com return) um terceiro vetor dinâmico contendo a união dos itens — cada código que aparece em pelo menos um dos esquadrões, sem repetição. Use um parâmetro ponteiro extra (ex.: int *n_total) para essa função também devolver o tamanho do vetor resultante.
  • Sem duplicatas: se um item aparece nos dois esquadrões (ou repetido dentro do mesmo esquadrão), ele deve aparecer uma única vez no inventário combinado.
  • Liberação de memória: ao final, libere com free os três vetores alocados (Esquadrão A, Esquadrão B e o inventário combinado) — nenhum deles pode vazar memória.

📊 Saída Esperada

Ao final, o programa deve exibir o inventário combinado e o total de itens únicos coletados pelos dois esquadrões juntos.

💻 Exemplo de Execução

Quantos itens o Esquadrão A coletou? 5
Digite os códigos dos itens do Esquadrão A: 1 3 5 6 7

Quantos itens o Esquadrão B coletou? 5
Digite os códigos dos itens do Esquadrão B: 1 3 4 6 8

===== Inventário Combinado =====
Itens: 1 3 4 5 6 7 8
Total de itens únicos: 7
Dica de Estudo: Revise o exemplo Soma elemento a elemento deste módulo para relembrar como alocar e devolver um vetor de dentro de uma função — o mesmo raciocínio vale aqui, só que o tamanho do vetor devolvido não é conhecido de antemão (ele depende de quantos itens são únicos). Uma estratégia comum é alocar um vetor "grande o suficiente" para o pior caso (n1 + n2 posições), preenchê-lo item por item conferindo se cada código já apareceu antes, e usar o parâmetro n_total para informar quantas posições desse vetor foram realmente usadas.
