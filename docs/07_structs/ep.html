📇 EP 07: Tipos Abstratos e Persistência

Entrega: 30 de Setembro

O Cenário: Este exercício é a base do Trabalho Prático I e da Prova — aqui você demonstra domínio em criar um tipo de dado próprio com typedef struct, alocar registros dinamicamente e manipulá-los sempre por ponteiro. A parte de arquivo já vem pronta no Código Base: seu trabalho é entender como um registro que vive na memória (a struct alocada com malloc) vira um registro num arquivo texto — e como volta de lá, num novo registro alocado, idêntico ao original.

📋 Requisitos Técnicos

  • Novo tipo: defina um tipo Time com typedef struct, contendo id (int), nome (string, até 49 caracteres + '\0') e pontos (int).
  • Alocação dinâmica: solicite os dados de um time ao usuário e aloque o registro dinamicamente, via ponteiro (malloc).
  • Acesso pelos campos: acesse sempre os campos do registro pelo operador seta (->), nunca pelo ponto.
  • Gravar e reler: use as funções de arquivo já fornecidas no Código Base (write_time_to_file/read_time_from_file) para gravar o time em time.txt e, depois, para carregá-lo de volta num novo ponteiro alocado.
  • Liberação de memória: libere a memória de cada ponteiro alocado (free) quando não precisar mais dele.
  • Sem variáveis globais.

void write_time_to_file(const char *filename, int id, const char *nome, int pontos)
{
    FILE *file = fopen(filename, "w");
    if (file == NULL)
    {
        perror("Erro ao abrir o arquivo para escrita");
        exit(1);
    }
    fprintf(file, "%d\n%s\n%d\n", id, nome, pontos);
    fclose(file);
}
