Ponteiros para estruturas

A seta é só um atalho

p é um ponteiro para uma struct com um campo x — as duas formas abaixo são idênticas.

(*p).x
desreferencia p, depois acessa o campo
≡
p->x
mesma coisa, escrita de um jeito mais direto

Alocação dinâmica de estruturas

Uma struct pode viver na pilha ou no heap

malloc(sizeof(...)) tira a struct da pilha e a coloca no heap, com vida própria.

struct point2d point;
pilha — existe enquanto a função existir
vs
malloc(sizeof(struct point2d))
heap — existe até um free explícito

Definição de novos tipos

typedef: um apelido para o tipo

Point2D e struct point2d são exatamente o mesmo tipo — só muda o que se escreve.

Sem typedef

struct point2d p;
struct point2d *ptr;

Com typedef

Point2D p;
Point2D *ptr;

Vetores de estruturas

Um polígono é só um vetor de pontos

Cada vértice é um Point2D; o polígono inteiro é um vetor dessas structs, na ordem dos vértices.

Fonte: Celes, W. Estrutura de Dados.

Vetores de estruturas

Point2D poligono[4] — quatro vértices, um vetor só

Cada posição já reserva espaço para um Point2D completo — sem vetores separados de x e de y.

p0(0.0, 0.0)
p1(4.0, 0.0)
p2(4.0, 3.0)
p3(0.0, 3.0)
06_union_enum_vector/main.c
Point2D poligono[4] = {
    {0.0, 0.0}, {4.0, 0.0},
    {4.0, 3.0}, {0.0, 3.0}
};

for (int i = 0; i < 4; i++)
    printf("p%d = (%.1f, %.1f)\n",
        i, poligono[i].x, poligono[i].y);

Tipo Union

Campos separados vs. espaço compartilhado

Uma struct reserva espaço para cada campo; uma union reserva um único espaço, do tamanho do maior campo.

struct

int i4 bytes
float f4 bytes
campos coexistem — 8 bytes ao todo

union

int i
float f4 bytes (compartilhados)
escrever num campo sobrescreve o outro
06_union_enum_vector/main.c
typedef union
{
    int como_inteiro;
    float como_real;
} Valor;

Valor v;
v.como_real = 3.14f;
printf("%lu bytes\n", sizeof(Valor));
// imprime: 4 bytes (não 4+4=8)
