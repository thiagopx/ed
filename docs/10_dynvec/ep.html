🏆 EP 09: Classificação do Campeonato (1 ponto)

Entrega: 31 de Outubro

O Cenário: Este EP é o primeiro passo rumo ao Trabalho Prático "Campeonato Computacional de Futebol" — aqui você só monta a estrutura que guarda os times inscritos, sem ainda processar nenhuma partida. Cada time tem um registro com nome, vitórias (V), empates (E), derrotas (D), gols marcados (GM) e gols sofridos (GS). O problema é que você não sabe, de antemão, quantos times existem no arquivo de entrada — por isso, em vez de um vetor de tamanho fixo, você vai usar a mesma técnica de vetor dinâmico deste módulo, agora aplicada a um registro inteiro (struct), e não a um float isolado.

⚽ Como se Calcula a Classificação

Saldo de Gols (S)
S = GM − GS — não é lido do arquivo, é calculado na hora de imprimir
Pontos Ganhos (PG)
PG = 3V + E — também calculado, nunca armazenado no registro

📋 Requisitos Técnicos

  • Registro: defina um tipo Team com os campos id (int), name (string), wins, draws, losses, goals_scored e goals_conceded (todos int). Saldo e pontos não entram no registro — são calculados a partir dos outros campos.
  • TAD do vetor dinâmico: implemente tv_create, tv_insert, tv_size, tv_get e tv_free para um vetor dinâmico de Team — a mesma técnica do exemplo de vetor dinâmico de float visto em aula, inclusive a realocação automática que dobra a capacidade quando o vetor enche.
  • Leitura: leia os times de um arquivo texto teams.csv, uma linha por time, no formato id,nome,V,E,D,GM,GS, sem assumir nenhum número fixo de times — insira cada time lido com tv_insert até o arquivo acabar.
  • Saída: imprima a tabela de classificação (ID, Time, V, E, D, GM, GS, Saldo, Pontos) na mesma ordem em que os times foram lidos do arquivo — sem ordenar (ordenação é assunto de um módulo futuro).

🧩 Código Base

A leitura do arquivo e a impressão da tabela já vêm prontas no main — o que falta, e é o conteúdo deste módulo, é o próprio TAD do vetor dinâmico: os campos de struct teamvec e o corpo das cinco funções abaixo.

#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int id;
    char name[50];
    int wins, draws, losses;
    int goals_scored, goals_conceded;
} Team;

typedef struct teamvec TeamVec;

// TODO: defina aqui os campos de "struct teamvec" -- pense no que o TAD
// precisa guardar para saber quantos times tem e quanto espaço ainda sobra
// struct teamvec { ... };

// TODO: implemente tv_create -- aloca o TAD e um vetor inicial pequeno (ex.: 4 times)
TeamVec *tv_create(void);

// TODO: implemente tv_insert -- se o vetor estiver cheio, dobre a capacidade
// (realloc) antes de inserir o novo time
void tv_insert(TeamVec *tv, Team t);

// TODO: implemente tv_size -- retorna o número de times atualmente guardados
int tv_size(TeamVec *tv);

// TODO: implemente tv_get -- retorna o time na posição i
Team tv_get(TeamVec *tv, int i);

// TODO: implemente tv_free -- libera o vetor interno e depois o TAD
void tv_free(TeamVec *tv);

int main(void) {
    FILE *f = fopen("teams.csv", "rt");
    if (f == NULL)
        return 1;

    TeamVec *tv = tv_create();
    Team t;
    while (fscanf(f, "%d,%49[^,],%d,%d,%d,%d,%d", &t.id, t.name, &t.wins,
                  &t.draws, &t.losses, &t.goals_scored, &t.goals_conceded) == 7)
        tv_insert(tv, t);
    fclose(f);

    printf("ID  Time            V   E   D   GM  GS  S   PG\n");
    for (int i = 0; i < tv_size(tv); i++) {
        Team t = tv_get(tv, i);
        int goal_diff = t.goals_scored - t.goals_conceded;
        int points = 3 * t.wins + t.draws;
        printf("%-3d %-15s %-3d %-3d %-3d %-3d %-3d %-3d %-3d\n",
               t.id, t.name, t.wins, t.draws, t.losses,
               t.goals_scored, t.goals_conceded, goal_diff, points);
    }

    tv_free(tv);
    return 0;
}
Dica: releia o exemplo de vetor dinâmico de float visto em aula. A struct do TAD guarda três coisas: o número atual de elementos, a capacidade do vetor e o próprio vetor alocado. A inserção só faz uma coisa antes de gravar o novo elemento: confere se o número atual já alcançou a capacidade e, se sim, dobra a capacidade com realloc. Troque float por Team e a lógica é exatamente a mesma.
