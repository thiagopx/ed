🖼️ EP 08: Leitor de Imagens PPM

Entrega: 10 de Outubro

O Cenário: Você vai implementar um leitor de imagens coloridas no formato PPM (Portable Pixel Map), um dos formatos de imagem mais simples que existem — texto puro, sem compressão. A função load_image_ppm do código base já vem com a estrutura pronta (a struct Image, a função write_image_to_ppm que grava uma imagem, e um main que só falta descomentar a chamada de leitura) — falta só implementar a leitura. Antes de começar, vale a pena se familiarizar com o formato PPM no modo texto (P3) em paulbourke.net/dataformats/ppm.

🗂️ Estrutura de um Arquivo PPM (P3)

Número Mágico
P3 — identifica o formato
Dimensões
largura e altura, em pixels
Valor Máximo
sempre 255 neste EP

📋 Requisitos Técnicos

  • Assinatura da Função: implemente somente o corpo de load_image_ppm(const char *filename, Image *image) — os passos esperados já estão indicados como comentários dentro dela.
  • Validação do formato: se o número mágico não for P3, ou o valor máximo de pixel não for 255, exiba uma mensagem de erro (o arquivo não segue o formato esperado por este EP).
  • Restrição: altere somente o corpo de load_image_ppm — a struct Image, a assinatura das funções e o restante do código base devem permanecer inalterados.

🖥️ Passos da Leitura

  1. Abrir o arquivo e verificar se foi aberto com sucesso.
  2. Ler o número mágico e validar que é P3.
  3. Ler a largura, a altura e o valor máximo de pixel (validando que é 255).
  4. Alocar a matriz de pixels de image com as dimensões lidas.
  5. Ler os três valores (R, G, B) de cada pixel, preenchendo a matriz.
  6. Fechar o arquivo.

💻 Exemplo de Execução

$ cat input.ppm
P3
2 2
255
255 0 0 0 255 0
0 0 255 255 255 0

$ gcc ep5.c -o ep5
$ ./ep5

$ diff input.ppm output.ppm
(sem diferenças — a imagem lida foi gravada de volta idêntica)
Dica: o campo data é um unsigned char *** — pense nele como um vetor de linhas, cada linha um vetor de colunas, e cada coluna um vetor de 3 valores (R, G, B). Aloque nível por nível, do mais externo (altura) para o mais interno (os 3 canais de cor).
