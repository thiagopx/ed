Comandos de repetição

Repetição e números aleatórios

Os comandos for e while repetem um bloco de código enquanto uma condição é verdadeira. Escolha um exemplo abaixo: para cada um você vê o código-fonte, uma explicação do laço e a simulação da execução passo a passo — sem precisar compilar nada.

Fatorial

ver no GitHub ↗ 
#include <stdio.h>

// Define o maior valor de fatorial calculável com int
#define MAX_FACTORIAL_VALUE 12

int main()
{
    int n;

    printf("Enter an integer: ");
    scanf("%d", &n);

    if (n < 0)
    {
        printf("Factorial is not defined for negative numbers.\n");
    }
    else if (n > MAX_FACTORIAL_VALUE)
    {
        printf("Factorial for values greater than %d cannot be computed with int data type.\n", MAX_FACTORIAL_VALUE);
    }
    else
    {
        int factorial = 1;

        // Calcula o fatorial usando um laço
        for (int i = 1; i <= n; ++i)
        {
            factorial *= i;
        }

        printf("Factorial of %d is %d\n", n, factorial);
    }

    return 0;
}

Como funciona o laço

for (int i = 1; i <= n; ++i) executa três passos a cada volta: testa i <= n, roda o corpo do laço se o teste for verdadeiro e, em seguida, incrementa i. A variável factorial acumula o produto — é o padrão clássico de "variável acumuladora" em um laço for.

Potência

ver no GitHub ↗ 
#include <stdio.h>

float calculate_power(float base, int exponent)
{
    float result = 1.0f;

    if (exponent >= 0)
        for (int i = 0; i < exponent; ++i)
            result *= base;
    else
        for (int i = 0; i < -exponent; ++i)
            result /= base;

    return result;
}

int main()
{
    float base, result;
    int exponent;

    printf("Enter the base: ");
    scanf("%f", &base);

    printf("Enter the exponent: ");
    scanf("%d", &exponent);

    result = calculate_power(base, exponent);

    printf("Result: %f\n", result);

    return 0;
}

Como funciona o laço

A função escolhe entre dois laços for conforme o sinal do expoente: multiplica result por base, exponent vezes, se o expoente for positivo; ou divide, -exponent vezes, se for negativo. Em ambos, result começa em 1.0f — o elemento neutro da multiplicação.

Rand

ver no GitHub ↗ 
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <limits.h>

int main()
{
    /** Set a seed based on the current time
     * In Linux, the time() function returns the elapsed time in seconds from
     * January 1, 1970, 00:00:00 (UTC) to the present moment.
     */
    // srand(time(NULL));
    srand(10);

    // Generate and display 5 random numbers
    printf("Random numbers generated:\n");
    for (int i = 0; i < 50; i++)
    {
        double random_number = (((double)rand()) / INT_MAX) * 10;
        printf("%lf\n", random_number);
    }

    return 0;
}

Como funciona o laço

Um computador não gera aleatoriedade "de verdade": rand() usa uma fórmula determinística que parte de uma semente (seed) definida por srand(). A mesma semente sempre produz a mesma sequência — por isso este exemplo usa srand(10) em vez de srand(time(NULL)).

A expressão ((double)rand() / INT_MAX) * 10 converte o inteiro bruto devolvido por rand() (entre 0 e INT_MAX = 2147483647) em um valor double entre 0 e 10.

Dados

ver no GitHub ↗ 
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

void roll_dice()
{
    int result = rand() % 6 + 1; // Generate a random number between 1 and 6 (like a dice roll)
    printf("You rolled a %d!\n", result);
}

int main()
{
    // Initialize the random number generator with the current time
    srand(time(NULL));

    printf("Welcome to the Virtual Dice Roll!\n");
    printf("Press Enter to roll the dice...");
    getchar();
    // Wait for Enter key press
    roll_dice();

    return 0;
}

Como funciona a função

void roll_dice() não devolve nenhum valor — ela só executa uma ação (sortear e imprimir o resultado) e devolve o controle para quem a chamou. O operador % (resto da divisão) é o que limita o sorteio ao intervalo de um dado: rand() % 6 dá sempre um resto entre 0 e 5; somando 1, o intervalo vira 1–6.

result é uma variável local: existe só enquanto roll_dice() está executando e desaparece quando a função termina.

Adivinhe o número

ver no GitHub ↗ 
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main()
{
    int number_to_guess, user_guess;
    srand(time(NULL)); // Seed the random number generator

    // Generate a random number between 1 and 100
    number_to_guess = rand() % 100 + 1;

    printf("Welcome to the Guessing Game!\n");
    printf("I have selected a number between 1 and 100. Try to guess it!\n");

    // Loop until the user guesses the correct number
    while (1)
    {
        printf("Enter your guess: ");
        scanf("%d", &user_guess);

        if (user_guess < number_to_guess)
        {
            printf("Too low! Try again.\n");
        }
        else if (user_guess > number_to_guess)
        {
            printf("Too high! Try again.\n");
        }
        else
        {
            printf("Congratulations! You guessed the correct number: %d\n", number_to_guess);
            break;
        }
    }

    return 0;
}

Como funciona o laço

while (1) nunca vira falso sozinho — 1 é sempre verdadeiro. Esse laço só termina quando o break lá dentro é executado, o que só acontece quando o palpite está correto. É o padrão "laço infinito + break", usado quando não se sabe, de antemão, quantas repetições serão necessárias.

number_to_guess é sorteado uma única vez, antes do laço. Repare que ele não muda entre as tentativas — só user_guess é lido de novo a cada volta.
Para lembrar. Use for quando o número de repetições é conhecido antes do laço começar (como percorrer de 1 até n). Use while quando a repetição depende de uma condição que só pode ser avaliada durante a execução — como no jogo "Adivinhe o número", que repete até o usuário acertar.
