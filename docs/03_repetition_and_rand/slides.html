Pré-teste vs. pós-teste

Quando a condição é testada muda tudo

do-while garante que o corpo rode pelo menos uma vez, mesmo que a condição já comece falsa.

Laço infinito, saída manual

Repete para sempre — até um break

while (1) nunca fica falso sozinho: só um break interrompe, tipicamente dentro de um if.

A semente decide a sequência inteira

srand(valor) define o ponto de partida de rand() — sem chamar srand, a sequência é sempre a mesma.

srand(10)

Semente fixa — útil para depurar ou reproduzir um resultado.

Execução 1: 5.65, 6.10, 5.05…
Execução 2: 5.65, 6.10, 5.05…

srand(time(NULL))

Semente pelo relógio — muda a cada segundo, então a sequência muda a cada execução.

Execução 1: 3.21, 7.48, 1.90…
Execução 2: 8.77, 2.05, 6.63…
