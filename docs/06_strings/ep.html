🔐 EP 06: Cifra de César

Entrega: 16 de Setembro

O Cenário: A Cifra de César é uma das criptografias mais antigas que se conhece: cada letra da mensagem é substituída pela letra que está N posições adiante no alfabeto (voltando ao início depois do Z), onde N é o deslocamento, combinado previamente entre quem envia e quem recebe a mensagem. Você foi encarregado de escrever um programa que cifra (e decifra) frases usando essa técnica.

🔡 Como o Deslocamento Funciona

Letras
Deslocadas N posições no alfabeto, preservando maiúscula/minúscula
Fim do alfabeto
Depois de Z (ou z) o deslocamento volta para A (ou a)
Outros caracteres
Espaços, pontuação e números não são alterados

📋 Requisitos Técnicos

  • Leitura da frase: a frase pode conter espaços — leia com um formato que capture a linha inteira (ex.: scanf(" %199[^\n]", frase)), nunca com %s.
  • Função dedicada: implemente uma função char *caesar_cipher(const char *texto, int deslocamento) que aloca e devolve (com malloc e return) uma nova string com o resultado, sem alterar a string original — o mesmo padrão do exemplo Duplicar uma string deste módulo, agora combinado com a lógica de deslocamento.
  • Preservação: letras minúsculas continuam minúsculas, maiúsculas continuam maiúsculas; qualquer caractere que não seja letra (espaço, pontuação, dígito) é copiado sem alteração.
  • Cifrar e decifrar: o programa deve perguntar se a operação é para cifrar ou decifrar — decifrar é equivalente a cifrar com o deslocamento negativo do mesmo valor.
  • Liberação de memória: libere com free a string devolvida por caesar_cipher antes do programa terminar.

💻 Exemplo de Execução

Digite a frase: Ataque ao amanhecer!
Digite o deslocamento: 3
Cifrar ou decifrar? (C/D): C

===== Resultado =====
Frase original: Ataque ao amanhecer!
Frase cifrada:  Dwdtxh dr dpdqkhfhu!
Dica de Estudo: Para deslocar uma letra, pense na posição dela dentro do próprio alfabeto — algo como letra - 'a' (ou 'A', para maiúsculas) dá um número de 0 a 25, sobre o qual dá pra somar o deslocamento e aplicar um módulo 26 antes de somar 'a' de volta. Cuidado com deslocamentos negativos (para decifrar): o operador % em C pode devolver um resultado negativo quando o número da esquerda é negativo — some 26 ao resultado do módulo antes de usá-lo, se ele vier negativo, para manter o índice dentro da faixa 0-25.
