✂️ EP 06: Tokenizando à Mão

Entrega: 16 de Setembro

O Cenário: Muitas ferramentas de texto precisam separar uma mensagem em partes — um comando do seu argumento, um nome do seu sobrenome. Você foi encarregado de desenvolver, na mão (sem usar strtok), uma função capaz de "tokenizar" uma string: dado um texto qualquer, ela deve encontrar o primeiro espaço em branco e separar a mensagem em duas partes distintas, devolvendo cada uma através de um parâmetro ponteiro.

📋 Requisitos Técnicos

  • Assinatura da Função: implemente a função com esta assinatura: int split_text(char *text, char *part1, char *part2); — part1 e part2 já chegam alocados (veja o código base), sua função só precisa preenchê-los.
  • Sucesso (retorno 1): se text contiver pelo menos um espaço em branco, preencha part1 com tudo antes do primeiro espaço e part2 com tudo depois dele, e devolva 1.
  • Falha (retorno 0): se não existir nenhum espaço em text, devolva 0 sem alterar part1/part2.
  • Terminação: tanto part1 quanto part2 precisam terminar com '\0' — sem ele, %s não sabe onde parar de imprimir.

💻 Exemplo de Execução

Entrada: "Bom dia"

Parte 1: Bom
Parte 2: dia

🧩 Código Base

Parta deste esqueleto — só a função split_text precisa ser implementada:

#include <stdio.h>
#include <string.h>

int split_text(char *text, char *part1, char *part2) {
    // Implemente sua lógica aqui
}

int main() {
    char text[] = "Bom dia";
    char part1[20], part2[20];

    if (split_text(text, part1, part2)) {
        printf("Parte 1: %s\nParte 2: %s\n", part1, part2);
    }
    return 0;
}
Dica de Estudo: Você pode percorrer text caractere por caractere até encontrar o espaço (' '), copiando cada caractere visitado para part1 — ou usar strchr(text, ' ') da string.h para localizar de uma vez a posição do separador. De qualquer forma, não esqueça: se não houver espaço, text inteiro fica sem ser dividido, e a função deve devolver 0 em vez de inventar um resultado.
