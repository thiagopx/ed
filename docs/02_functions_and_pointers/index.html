Funções e ponteiros

Dividindo o programa em funções

Funções deixam um programa organizado em pedaços pequenos e reutilizáveis: cada uma recebe parâmetros e pode devolver um valor de retorno. Já os ponteiros guardam endereços de memória em vez de valores comuns — com eles, uma função consegue alterar variáveis de quem a chamou, algo que só o retorno não resolveria. Escolha um exemplo abaixo: para cada um você vê o código-fonte, uma explicação da mecânica central e a simulação da execução passo a passo — sem precisar compilar nada.

Exemplos

  • 🔗Volume do cilindro

    Uma função recebe parâmetros e devolve o volume calculado pelo return.

  • 🔗Ponteiros básicos

    Os operadores & e * revelam e alteram o conteúdo de um endereço de memória.

  • 🔗Soma e diferença

    Uma função sem retorno escreve dois resultados via ponteiros passados por parâmetro.

  • 🔗Contador de chamadas

    Uma variável static preserva seu valor entre chamadas sucessivas da função.

  • 🔗Macro do quadrado

    #define expande texto antes da compilação — não é uma chamada de função de verdade.

Volume do cilindro

ver no GitHub ↗ 
#include <stdio.h>
#include <math.h>

// Function to calculate volume of a cylinder
double cylinder_volume(double radius, double height)
{
    return M_PI * pow(radius, 2) * height;
    // return M_PI * radius * radius * height;
}

int main()
{
    double radius, height;

    printf("Enter the radius of the cylinder: ");
    scanf("%lf", &radius);

    printf("Enter the height of the cylinder: ");
    scanf("%lf", &height);

    double volume = cylinder_volume(radius, height);

    printf("\nCylinder Parameters:\n");
    printf("Radius: %.2lf\n", radius);
    printf("Height: %.2lf\n", height);
    printf("Volume: %.2lf\n", volume);

    return 0;
}

Como funciona a função

cylinder_volume é definida antes de main, com dois parâmetros (radius, height) e retorno double. Ao ser chamada em cylinder_volume(radius, height), a execução salta para dentro da função: os valores de radius e height de main são copiados para os parâmetros locais da função. O return calcula o volume e devolve esse valor para quem chamou — a expressão cylinder_volume(radius, height) "vira" esse valor, que é atribuído a volume.

Ponteiros básicos

ver no GitHub ↗ 
#include <stdio.h>

int main()
{
    // Declare an integer variable
    int num = 42;

    // Declare a pointer to an integer
    int *ptr;

    // Assign the address of 'num' to the pointer
    ptr = &num;

    // Display the original value of 'num', the address stored in 'ptr',
    // and the value pointed to by 'ptr'
    printf("Original num value: %d\n", num);
    printf("Address stored in ptr: %p\n", (void *)ptr); // Note the typecast
    printf("Value pointed to by ptr: %d\n", *ptr);

    // Modify the value of 'num' through the pointer
    *ptr = 100;

    // Display the updated value of 'num', the address stored in 'ptr',
    // and the value pointed to by 'ptr'
    printf("Updated num value: %d\n", num);
    printf("Address stored in ptr: %p\n", (void *)ptr); // Note the typecast
    printf("Value pointed to by ptr: %d\n", *ptr);

    return 0;
}

Como funcionam & e *

&num ("endereço de") devolve a posição de memória onde num está guardado; ptr armazena esse endereço. *ptr ("conteúdo de") acessa o valor guardado naquele endereço — por isso *ptr e num sempre têm o mesmo valor: são o mesmo espaço de memória visto de dois jeitos diferentes. Alterar *ptr altera num, mesmo sem escrever num diretamente.

Soma e diferença

ver no GitHub ↗ 
#include <stdio.h>

// Function to calculate sum and difference of two double values
void calculate_sum_and_difference(
    double a, double b, double *sum, double *difference)
{
    *sum = a + b;
    *difference = a - b;
}

int main()
{
    double num1, num2, sum, difference;

    printf("Enter the first number: ");
    scanf("%lf", &num1);

    printf("Enter the second number: ");
    scanf("%lf", &num2);

    calculate_sum_and_difference(num1, num2, &sum, &difference);

    printf("Sum: %.2lf\n", sum);
    printf("Difference: %.2lf\n", difference);

    return 0;
}

Por que ponteiros aqui

Uma função só consegue return um único valor — mas aqui precisamos de dois resultados (soma e diferença). A saída é passar os endereços de sum e difference (com &sum, &difference): a função recebe esses endereços em double *sum, double *difference e escreve diretamente neles com *sum = ... e *difference = .... Por isso a função nem precisa de return — é declarada void.

Contador de chamadas

ver no GitHub ↗ 
#include <stdio.h>

// Function with a local static variable
int count_calls()
{
    static int counter = 0; // Local static variable

    counter++; // Increment the counter
    return counter;
}

int main()
{
    printf("Function has been called %d times.\n", count_calls());
    printf("Function has been called %d times.\n", count_calls());
    printf("Function has been called %d times.\n", count_calls());
    printf("Function has been called %d times.\n", count_calls());
    printf("Function has been called %d times.\n", count_calls());

    return 0;
}

Como funciona static aqui

Uma variável local comum nasce e morre a cada chamada da função. static int counter = 0; é diferente: a inicialização com 0 só acontece uma única vez, na primeira chamada — nas chamadas seguintes, counter já existe e mantém o valor que tinha ao final da chamada anterior. É assim que a função "lembra" quantas vezes já foi chamada.

static não é a mesma coisa que variável global: counter continua existindo entre chamadas (como uma global), mas só é visível dentro de count_calls — nenhuma outra função enxerga ou altera esse counter diretamente.

Macro do quadrado

ver no GitHub ↗ 
#include <stdio.h>

// Define a macro to calculate the square of a number
#define SQUARE(x) ((x) * (x))

int main()
{
    int num = 5;
    int squared = SQUARE(num);

    printf("The square of %d is %d\n", num, squared);

    return 0;
}

Macro não é função

#define é uma diretiva de pré-processador: antes mesmo da compilação, todo texto SQUARE(num) é substituído, literalmente, por ((num) * (num)). Não existe chamada de função, parâmetro ou retorno — é apenas troca de texto. Os parênteses em ((x) * (x)) não são um capricho: protegem a expressão contra problemas de precedência quando o argumento não é um nome simples (ex.: SQUARE(1 + 2) vira ((1 + 2) * (1 + 2)) = 9, e não 1 + 2 * 1 + 2 = 5, se faltassem os parênteses).

Compile com gcc square_macro.c -o square_macro -E (ou --save-temps) para ver o código já com a macro expandida, antes da compilação de verdade — é uma boa forma de enxergar o que o pré-processador faz.
Para lembrar. Funções recebem parâmetros por cópia e podem devolver um único valor por return; para alterar variáveis de quem chamou — ou "retornar" mais de um valor — passe endereços (ponteiros) como parâmetro. static preserva o valor de uma variável local entre chamadas, mas continua visível só dentro da função. Uma macro (#define) não é uma função: é texto substituído antes da compilação.
