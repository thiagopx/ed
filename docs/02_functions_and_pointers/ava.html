🧪 Desafio Prático de Compilação

Compile um dos exemplos (ex.: pointer.c) no terminal utilizando as duas abordagens a seguir:

1. Compilação direta: 
gcc pointer.c -o <nome_do_programa>
2. Compilação preservando arquivos intermediários: 
gcc --save-temps pointer.c -o <nome_do_programa>
