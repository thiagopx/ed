📐 EP 02: Geometria e Ponteiros

Entrega: 21 de Março

O Objetivo: Desenvolver um programa que calcule as propriedades de um retângulo. O foco deste exercício é o uso de passagem de parâmetros por referência utilizando ponteiros em C.

📋 Requisitos Técnicos

  • Assinatura da Função: Implemente a função calc_info_retangulo. Ela deve receber o altura e largura (base), e "retornar" a área, o perímetro e a diagonal via ponteiros.
  • Tipagem: Todas as dimensões e cálculos devem utilizar o tipo de ponto flutuante (float ou double).
  • Restrição: É estritamente proibido o uso de variáveis globais. Toda a comunicação entre main e a função deve ocorrer via parâmetros.

📐 Cálculos Necessários

Sua função deve ser capaz de processar:

Área
base × altura
Perímetro
2 × (base + altura)
Diagonal
√(base² + altura²)

🖥️ Fluxo do Programa

  1. Solicitar comprimento e largura ao usuário.
  2. Declarar variáveis no main para armazenar os resultados.
  3. Chamar a função passando os endereços dessas variáveis.
  4. Exibir os resultados formatados na tela.

💻 Exemplo de Execução

Digite a base do retângulo: 4
Digite a altura do retângulo: 3

===== Propriedades do Retângulo =====
Área: 12.00
Perímetro: 14.00
Diagonal: 5.00
Dica Técnica: Para o cálculo da diagonal, utilize a função sqrt() da biblioteca math.h. Lembre-se de compilar usando a flag -lm no terminal, se necessário.
