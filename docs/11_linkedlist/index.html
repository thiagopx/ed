Listas encadeadas

Notas da aula sobre listas encadeadas: uma estrutura que aloca memória para cada elemento no momento em que ele é inserido e liga os elementos por ponteiros, em vez de guardá-los lado a lado. Partimos da lista simplesmente encadeada de inteiros e chegamos às variações — com ponteiro para o último, recursiva, circular, duplamente encadeada, de tipos estruturados e heterogênea. Cada operação vem com o código real, o custo e simulações passo a passo nos casos que mais confundem; cada estrutura, com suas vantagens, desvantagens e limitações.

Listas encadeadas

Até aqui, para guardar um conjunto de dados usamos vetores. Um vetor ocupa um espaço contíguo de memória, e é isso que permite o acesso direto a qualquer elemento por v[i]: o endereço do i-ésimo elemento é calculado com uma conta, sem visitar os anteriores. O preço é a rigidez. Um vetor estático precisa ser dimensionado antes de usar; o vetor dinâmico do módulo anterior cresce com realloc, mas cada realocação pode copiar todos os elementos para outro lugar da memória — o gargalo do vetor dinâmico.

A lista encadeada troca essas propriedades de lugar. Cada elemento é alocado sozinho, no momento em que é inserido, e liberado sozinho, quando é removido: a memória ocupada acompanha exatamente o número de elementos, e nenhuma inserção obriga a mover os demais. Como os elementos não ficam lado a lado, cada um precisa guardar onde está o próximo — e perde-se o acesso direto: para chegar ao i-ésimo, é preciso passar pelos anteriores. Quase tudo neste módulo é consequência dessa troca, e a seção Comparando as estruturas, no fim, reúne os custos lado a lado.

Como ler os custos. Dizemos que uma operação custa O(1) (constante) quando o trabalho não depende do tamanho n da lista, e O(n) (linear) quando, no pior caso, ela visita os n nós. Inserir no início de uma lista é O(1); procurar um valor é O(n).

Listas simplesmente encadeadas

Nós e a estrutura da lista

Uma lista encadeada é uma sequência de nós. Cada nó guarda a informação (info) e um ponteiro para o próximo nó (next); o último guarda NULL como próximo, marcando o fim. A lista em si só precisa conhecer o primeiro nó: a partir dele, segue-se next até chegar a NULL. Em C, isso são duas estruturas — o nó e a lista —, escondidas atrás de um TAD: o linkedlist.h só declara os tipos LinkedList e ListNode, e quem usa a lista nunca mexe em first ou next diretamente.

01_linkedlist/linkedlist.c

// Define a structure for the linked list.
struct list
{
    ListNode *first; // A pointer to the first node in the linked list.
};

// Define a structure for a node in the linked list.
struct list_node
{
    int info;       // An integer value stored in the node.
    ListNode *next; // A pointer to the next node in the linked list.
};

Repare que ListNode é autorreferente: o nó contém um ponteiro para outro nó do mesmo tipo. Por isso o typedef vem antes, no .h, e a estrutura pode usar o nome ListNode dentro dela mesma.

Criar a lista é alocar a estrutura e fazer first = NULL: a lista vazia é a que não tem primeiro nó. Por isso testar se a lista está vazia também é uma comparação só. As duas operações são O(1).

01_linkedlist/linkedlist.c

// Function to create an empty linked list and return a pointer to it.
LinkedList *ll_create()
{
    LinkedList *l = (LinkedList *)malloc(sizeof(LinkedList)); // Allocate memory for the list structure.
    l->first = NULL;                                          // Initialize the 'first' pointer to NULL, indicating an empty list.
    return l;                                                 // Return a pointer to the newly created list.
}

// Function to check whether the linked list is empty.
int ll_is_empty(LinkedList *l)
{
    return l->first == NULL; // Check if the 'first' pointer is NULL, indicating an empty list.
}

Adaptado de: Celes, W. Estrutura de Dados.

Por que malloc e não uma variável local? Se ll_create declarasse LinkedList l; e devolvesse &l, devolveria o endereço de uma variável que deixa de existir quando a função termina: quem chamou ficaria com um ponteiro pendente. Uma estrutura que precisa viver além da função que a criou tem de ser alocada dinamicamente.

Inserir no início

A inserção mais simples coloca o novo elemento no início. A função aloca um nó, guarda nele a informação, faz o nó novo apontar para o que era o primeiro e, por fim, faz first apontar para o nó novo. A ordem importa: se first fosse atualizado antes, o endereço do antigo primeiro se perderia. Nenhum nó existente é visitado, então o custo é O(1), qualquer que seja o tamanho da lista — e a lista vazia não é caso especial, porque o nó novo simplesmente aponta para o NULL que estava em first.

01_linkedlist/linkedlist.c

// Function to insert an element at the beginning of the linked list.
void ll_insert(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;                                        // Set the 'info' field of the new node to the provided value.
    node->next = l->first;                                 // Make the new node point to the current first node.
    l->first = node;                                       // Update the 'first' pointer to point to the new node.
}

Adaptado de: Celes, W. Estrutura de Dados.

As simulações abaixo mostram a mesma função em três situações. Compare a lista vazia com o caso geral: as quatro linhas são as mesmas.

Uma consequência que costuma surpreender: inserir 1, 2 e 3, nessa ordem, produz a lista 3 2 1. Cada valor passa à frente dos anteriores.

Percorrer: imprimir, contar e buscar

Percorrer a lista é o padrão mais usado do módulo: um ponteiro p começa em first e avança com p = p->next até virar NULL. Ele faz o papel do índice do vetor. Imprimir e contar visitam todos os nós (O(n)); buscar pode parar antes, mas no pior caso — valor ausente ou no fim — também visita todos.

01_linkedlist/linkedlist.c

// Function to get the size (number of elements) of the linked list.
int ll_size(LinkedList *l)
{
    int cnt = 0; // Initialize a counter to zero.
    for (ListNode *p = l->first; p != NULL; p = p->next)
    {
        cnt++; // Increment the counter for each node in the list.
    }
    return cnt; // Return the total number of elements in the linked list.
}

// Function to verify if a value is in the list
int ll_is_in(LinkedList *l, int v)
{
    ListNode *p = l->first;
    while (p != NULL)
    {
        if (p->info == v)
            return 1;
        p = p->next;
    }
    return 0;
}

// Function to display all elements of the linked list.
void ll_print(LinkedList *l)
{
    for (ListNode *p = l->first; p != NULL; p = p->next)
    {
        printf("%d ", p->info); // Print the 'info' field of each node.
    }
    printf("\n"); // Print a newline character to separate the output.
}

Adaptado de: Celes, W. Estrutura de Dados.

Na lista vazia, p já começa NULL e o laço não executa nenhuma vez: contar devolve 0, buscar devolve 0. Escrever o laço com a condição p != NULL antes de usar p é o que torna a lista vazia um caso que não precisa de tratamento à parte.

Anexar no fim

Anexar no fim exige achar o último nó — e a lista só conhece o primeiro. A função percorre até o nó cujo next é NULL e o faz apontar para o nó novo. Esse percurso torna a operação O(n), e é o principal argumento para guardar também um ponteiro para o último nó (veja Lista com ponteiro para o último). Aqui, a lista vazia é caso especial: não há último nó para ligar, e o nó novo vira o primeiro.

01_linkedlist/linkedlist.c

// Function to append an element to the end of the linked list.
// Without a pointer to the last node, the whole list must be walked: cost grows with n.
void ll_append(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;
    node->next = NULL; // The new node will be the last one.

    if (l->first == NULL) // Empty list: the new node is also the first one.
    {
        l->first = node;
        return;
    }

    ListNode *p = l->first;
    while (p->next != NULL) // Stop at the current last node.
        p = p->next;
    p->next = node; // Link the old last node to the new one.
}

Manter a lista ordenada

Quando a ordem dos elementos importa, cada novo elemento é encadeado já no lugar certo. Percorre-se a lista até o primeiro nó cujo valor não é menor que o novo, guardando durante o percurso um ponteiro para o nó anterior (prev): é ele que vai passar a apontar para o novo nó. Numa lista simplesmente encadeada, um nó não sabe quem vem antes dele — por isso o anterior tem de ser guardado enquanto se anda. Esse padrão, "andar guardando o anterior", reaparece na remoção e em boa parte dos problemas sobre listas.

01_linkedlist/linkedlist.c

// Function to insert an element while keeping the list in ascending order.
void ll_insert_sorted(LinkedList *l, int v)
{
    ListNode *prev = NULL;  // Node that will precede the new one.
    ListNode *p = l->first; // Node used to walk the list.

    // Find the insertion point: first node whose value is not smaller than v.
    while (p != NULL && p->info < v)
    {
        prev = p;
        p = p->next;
    }

    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;

    if (prev == NULL) // Insert at the beginning (empty list or v is the smallest).
    {
        node->next = l->first;
        l->first = node;
    }
    else // Insert in the middle or at the end, right after 'prev'.
    {
        node->next = prev->next;
        prev->next = node;
    }
}

Adaptado de: Celes, W. Estrutura de Dados.

Se o percurso termina com prev ainda NULL, o novo elemento é menor que todos (ou a lista estava vazia) e vai para o início; senão, vai logo depois de prev — no meio ou no fim. Os quatro cenários abaixo cobrem as quatro saídas possíveis do laço.

O arquivo linkedlist.h também declara ll_is_sorted, que confere se a lista está em ordem crescente. Ela fica como exercício (caderno, seção de listas encadeadas): antes de escrever o laço, decida o que a função deve responder para a lista vazia e para a lista de um nó.

Retirar um elemento

Para retirar um elemento, percorre-se a lista guardando o anterior, como na inserção ordenada. Achado o nó, refaz-se o encadeamento para pulá-lo e só então ele é liberado. Há dois casos. Se o nó é o primeiro (prev é NULL), quem muda é first; senão, quem muda é o next do anterior. Retirar o último não é caso especial: o anterior passa a apontar para o NULL que o último guardava. A função devolve 1 se achou o valor e 0 se não achou; o custo é O(n), pela busca.

01_linkedlist/linkedlist.c

// Function to remove the first occurrence of a specific element from the linked list
int ll_remove(LinkedList *l, int v)
{
    ListNode *p = l->first; // Pointer to the current node being examined
    ListNode *prev = NULL;  // Pointer to the previous node

    // Traverse the list
    while (p != NULL)
    {
        // Check if the current node contains the element to be removed
        if (p->info == v)
        {
            // If the element to be removed is at the beginning of the list
            if (prev == NULL)
                l->first = p->next; // Update the 'first' pointer to skip the first node
            // If the element to be removed is in the middle or end of the list
            else
                prev->next = p->next; // Update the 'next' pointer of the previous node

            free(p);  // Deallocate memory occupied by the removed node
            return 1; // Indicate success (element found and removed)
        }
        else
        {
            prev = p;    // Update the 'prev' pointer
            p = p->next; // Move to the next node
        }
    }

    return 0; // Indicate that the element was not found
}

Adaptado de: Celes, W. Estrutura de Dados.

Os seis cenários abaixo são os que mais aparecem em erros: lista vazia, nó único, primeiro, meio, último e valor ausente. Repare que o único que mexe em first é o do primeiro nó — inclusive quando ele é o único.

Retirar todas as ocorrências pode reaproveitar ll_remove, chamando-a enquanto ela devolver 1. É correto, mas cada chamada recomeça do primeiro nó: com k ocorrências, o custo vira O(k·n). Na lista duplamente encadeada, mais adiante, a mesma operação é feita numa passada só.

01_linkedlist/linkedlist.c

// Remove all elements that match a specific value from the linked list
void ll_remove_all(LinkedList *l, int v)
{
    while (ll_remove(l, v))
        ;
}

Liberar a lista

Liberar a lista é liberar cada nó e, por fim, a estrutura. O cuidado é guardar o próximo antes do free: depois de liberado, o nó não pode mais ser lido, e p->next seria um acesso a memória que já não é do programa (o compilador não acusa; o erro aparece, quando aparece, na execução).

01_linkedlist/linkedlist.c

// Function to free the memory used by the linked list.
void ll_free(LinkedList *l)
{
    ListNode *p = l->first;
    while (p != NULL)
    {
        ListNode *t = p->next; // Store a reference to the next node.
        free(p);               // Free the memory allocated for the current node.
        p = t;                 // Move to the next node.
    }
    free(l); // Free the memory allocated for the list structure itself.
}

Adaptado de: Celes, W. Estrutura de Dados.

Construir uma lista a partir de um vetor

ll_from_array monta a lista na mesma ordem de um vetor. Chamar ll_append para cada valor custaria O(n²), porque cada chamada percorre a lista até o fim; em vez disso, a função guarda localmente o último nó criado e anexa depois dele em O(1), e o total fica O(n). O vetor não muda, e a lista nova precisa ser liberada separadamente.

01_linkedlist/linkedlist.c

// Function to build a new list with the n values of array v, in the same order.
LinkedList *ll_from_array(int v[], int n)
{
    LinkedList *l = ll_create();
    ListNode *last = NULL; // Last node built so far: appending after it costs O(1).
    for (int i = 0; i < n; i++)
    {
        ListNode *node = (ListNode *)malloc(sizeof(ListNode));
        node->info = v[i];
        node->next = NULL;
        if (last == NULL)
            l->first = node; // The first value starts the list.
        else
            last->next = node;
        last = node;
    }
    return l;
}

O linkedlist.h declara mais duas operações que produzem listas novas sem alterar as originais: ll_reversed (uma cópia em ordem inversa) e ll_concatenate (os valores de l1 seguidos dos de l2). Elas ficam como exercício no caderno. Uma pista para a primeira: lembre o que acontece com a ordem quando se insere sempre no início.

Problema resolvido: remover valores repetidos

Problema. Dada uma lista, remover os valores repetidos, mantendo só a primeira ocorrência de cada um: 4 2 4 7 2 2 9 4 deve virar 4 2 7 9.

Estratégia. Combina duas operações já vistas: percorrer e retirar guardando o anterior. Para cada nó p, um segundo ponteiro q percorre o resto da lista, com seu próprio anterior (prev), e retira toda cópia de p->info. Ao retirar, prev fica onde está e só q avança — exatamente como em ll_remove. O primeiro nó nunca é retirado (ele é a primeira ocorrência do próprio valor), então first não muda. Custo: O(n²) no pior caso, pelos dois percursos encaixados.

01_linkedlist/linkedlist.c

// Function to remove repeated values, keeping only the first occurrence of each one.
// For each node, a second walk (q, with its own prev) removes the later copies of the same value.
void ll_remove_duplicates(LinkedList *l)
{
    for (ListNode *p = l->first; p != NULL; p = p->next)
    {
        ListNode *prev = p;    // The node before q; starts at p itself.
        ListNode *q = p->next; // Walks the rest of the list looking for copies of p->info.
        while (q != NULL)
        {
            if (q->info == p->info)
            {
                prev->next = q->next; // Skip the copy...
                free(q);              // ...and free it.
                q = prev->next;       // prev stays where it is.
            }
            else
            {
                prev = q;
                q = q->next;
            }
        }
    }
}

Ficha: lista simplesmente encadeada

Vantagens
  • Cresce e diminui um nó por vez, sem realocar nem copiar os demais.
  • Inserir e retirar no início custam O(1).
  • Memória proporcional ao número de elementos, sem reserva ociosa.
Desvantagens
  • Sem acesso direto: chegar ao i-ésimo elemento custa O(i).
  • Sem ponteiro para o último, anexar no fim custa O(n).
  • Só anda num sentido: o anterior de um nó tem de ser guardado durante o percurso.
  • Cada elemento gasta memória extra com o ponteiro next (8 bytes numa máquina de 64 bits), além do custo de uma alocação por nó.
Limitações impostas por C
  • Não há coleta de lixo: cada nó alocado precisa de um free, na ordem certa (guardar o próximo antes).
  • Um ponteiro para um nó já liberado (ponteiro pendente) continua compilando e "funcionando" às vezes — o erro só aparece na execução, e de forma imprevisível.
  • A lista é só de int: para outro tipo, o código tem de ser reescrito (ou recorrer a void *, como na lista heterogênea).

Lista com ponteiro para o último

Guardar, além de first, um ponteiro last para o último nó muda o custo de duas operações: anexar no fim e juntar duas listas passam a ser O(1). O nó é o mesmo da lista simples; só a estrutura da lista ganha um campo. Em troca, toda operação que pode mudar o último nó precisa manter last correto — e é aí que moram os erros.

08_linkedlist-last/linkedlist.c

// The list keeps both ends: 'first' to start walking, 'last' to append without walking.
struct list
{
    ListNode *first; // A pointer to the first node (NULL if the list is empty).
    ListNode *last;  // A pointer to the last node (NULL if the list is empty).
};

// Define a structure for a node in the linked list.
struct list_node
{
    int info;       // An integer value stored in the node.
    ListNode *next; // A pointer to the next node in the linked list.
};

Anexar não percorre nada: o nó novo é ligado depois de last. A lista vazia é o caso que exige atenção: sem último nó, o novo vira o primeiro e o último.

08_linkedlist-last/linkedlist.c

// Function to append an element to the end: no walk, thanks to 'last'.
void ll_append(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode));
    node->info = v;
    node->next = NULL;
    if (l->last == NULL) // Empty list: the new node is first AND last.
        l->first = node;
    else
        l->last->next = node; // Link after the current last node.
    l->last = node;
}

Retirar é a mesma função da lista simples com um cuidado a mais: se o nó retirado é o último, last recua para o anterior — que é NULL se a lista ficou vazia. Esquecer essa linha deixa last apontando para um nó liberado, e o próximo ll_append escreve em memória que já não pertence à lista.

08_linkedlist-last/linkedlist.c

// Function to remove the first occurrence of v.
// Same walk as in 01_linkedlist, plus one extra care: removing the last node moves 'last'.
int ll_remove(LinkedList *l, int v)
{
    ListNode *prev = NULL;
    ListNode *p = l->first;
    while (p != NULL && p->info != v)
    {
        prev = p;
        p = p->next;
    }
    if (p == NULL) // Not found.
        return 0;

    if (prev == NULL)
        l->first = p->next; // Removing the first node.
    else
        prev->next = p->next;

    if (p == l->last)
        l->last = prev; // The node before it becomes the last (NULL if the list emptied).

    free(p);
    return 1;
}

Juntar duas listas (ll_join) mostra o ganho de last: os nós de l2 são movidos para o fim de l1 ligando o último de l1 ao primeiro de l2, sem percorrer nem copiar nada. Depois disso, l2 precisa ficar vazia — senão as duas listas "possuiriam" os mesmos nós, e liberar as duas liberaria cada nó duas vezes. Os casos com uma das listas vazia são tratados à parte.

08_linkedlist-last/linkedlist.c

// Function to move every node of l2 to the end of l1, only adjusting pointers.
void ll_join(LinkedList *l1, LinkedList *l2)
{
    if (l2->first == NULL) // Nothing to move.
        return;

    if (l1->first == NULL) // l1 empty: it simply takes l2's chain.
        l1->first = l2->first;
    else
        l1->last->next = l2->first; // Hook l2's chain after l1's last node.
    l1->last = l2->last;

    l2->first = l2->last = NULL; // l2 no longer owns those nodes.
}

Problema resolvido: intercalar duas listas ordenadas movendo os nós

Problema. Dadas duas listas em ordem crescente, produzir uma lista ordenada com todos os elementos, sem alocar nenhum nó: 1 4 9 e 2 3 10 12 viram 1 2 3 4 9 10 12, e as duas listas de origem ficam vazias.

Estratégia. A cada passo, o menor elemento ainda não usado está no início de uma das duas listas. Desliga-se esse primeiro nó da sua lista (atualizando first e, se ela esvaziou, last) e anexa-se o nó ao fim da lista resultado — em O(1), graças a last. Cada nó é movido uma vez: O(n + m), e nenhuma alocação além da estrutura da lista nova.

08_linkedlist-last/linkedlist.c

// Function to merge two ascending lists into a new one, moving their nodes.
LinkedList *ll_merge_sorted(LinkedList *a, LinkedList *b)
{
    LinkedList *r = ll_create();
    while (a->first != NULL || b->first != NULL)
    {
        LinkedList *from; // The list whose first node is the smallest.
        if (b->first == NULL || (a->first != NULL && a->first->info <= b->first->info))
            from = a;
        else
            from = b;

        ListNode *node = from->first; // Unlink the first node of 'from'...
        from->first = node->next;
        if (from->first == NULL)
            from->last = NULL;

        node->next = NULL; // ...and append it to r (O(1) with 'last').
        if (r->last == NULL)
            r->first = node;
        else
            r->last->next = node;
        r->last = node;
    }
    return r;
}

Ficha: lista com ponteiro para o último

Vantagens
  • Anexar no fim e juntar listas em O(1).
  • Base natural para uma fila (entra no fim, sai do início), que veremos adiante.
Desvantagens
  • Retirar o último continua O(n): é preciso achar o penúltimo, e só se anda para frente.
  • Mais um campo para manter correto em toda inserção e remoção.
Limitações impostas por C
  • Nada impede que last fique desatualizado: a consistência entre first, last e os nós é responsabilidade do programador do TAD.

Implementações recursivas

Uma lista encadeada tem uma definição recursiva natural: um encadeamento ou é vazio (NULL), ou é um nó seguido de outro encadeamento — o subencadeamento que começa em p->next. Quase toda operação pode seguir essa definição: resolve-se o caso vazio diretamente (o caso base) e, no caso não vazio, trata-se o nó atual e delega-se o resto à própria função.

Como a lista é um TAD, a recursão não acontece sobre LinkedList, mas sobre ListNode *. Cada operação pública chama uma função auxiliar static (visível só dentro de linkedlist.c) que recebe o primeiro nó. Tamanho e soma seguem a definição ao pé da letra: zero para o vazio; um (ou o valor do nó) mais o resultado do resto.

02_linkedlist-recursive/linkedlist.c

static int _ll_size(ListNode *p)
{
   if (p != NULL)
      return 1 + _ll_size(p->next);

   return 0;
}

// Function to get the size (number of elements) of the linked list.
int ll_size(LinkedList *l)
{
   return _ll_size(l->first);
}

static int _ll_sum(ListNode *p)
{
   if (p != NULL)
      return _ll_sum(p->next) + p->info;

   return 0;
}

int ll_sum(LinkedList *l)
{
   return _ll_sum(l->first);
}

Nas operações que mudam o encadeamento, a auxiliar devolve o novo início do subencadeamento, e quem chama grava esse retorno: p->next = _ll_remove(p->next, val), e, em cima de tudo, l->first = _ll_remove(l->first, val). Assim, retirar o primeiro nó deixa de ser caso especial: a chamada mais externa simplesmente devolve o segundo nó, e é ele que vira first.

static ListNode *_ll_insert_sorted(ListNode *p, int v)
{

      node->info = v;
      node->next = p; // The rest of the chain (possibly empty) comes after it.
      return node;
   }
   p->next = _ll_insert_sorted(p->next, v); // Insert into the subchain and relink.
   return p;
}

// Recursive helper: appending to a chain is appending to its subchain.
static ListNode *_ll_append(ListNode *p, int v)
{
   if (p == NULL) // Base case: empty chain; the new node is the whole chain.
   {
      ListNode *node = (ListNode *)malloc(sizeof(ListNode));
      node->info = v;
      node->next = NULL;
      return node;
   }
   p->next = _ll_append(p->next, v);
   return p;
}

// Recursive helper: removes every node whose value is val.
static ListNode *_ll_remove_all(ListNode *p, int val)
{
   if (p == NULL) // Base case: nothing to remove in an empty chain.
      return NULL;
   p->next = _ll_remove_all(p->next, val); // Clean the subchain first.
   if (p->info == val)                     // Then decide about this node.
   {
      ListNode *rest = p->next;
      free(p);
      return rest;
   }
   return p;
}

Comparar duas listas é comparar os primeiros nós e delegar o resto, com dois casos base — as duas acabaram juntas (iguais) ou só uma acabou (tamanhos diferentes).

Listas circulares

Em algumas aplicações, os elementos formam um ciclo: depois do último vem de novo o primeiro, como jogadores numa mesa ou processos que se revezam no processador. Numa lista circular, o next do último nó, em vez de NULL, aponta para o primeiro. Não há mais fim: a estrutura só precisa de um ponteiro para algum nó, que serve de ponto de partida.

Sem NULL, o critério de parada muda: percorre-se até voltar ao ponto de partida. Como o primeiro nó é também o critério de parada, o laço precisa executar o corpo antes de testar — o do … while. Com um while comum, a condição p != l->first seria falsa logo de saída. A lista vazia (first == NULL) é testada antes.

03_circular-linkedlist/linkedlist.c

// Function to get the number of elements in the list.
int ll_size(LinkedList *l)
{
    int cnt = 0;
    ListNode *p = l->first;
    if (p != NULL)
        do
        {
            cnt++;
            p = p->next;
        } while (p != l->first); // Stop when we are back at the start.
    return cnt;
}

// Function to display all elements, starting from the first.
void ll_print(LinkedList *l)
{
    ListNode *p = l->first;
    if (p != NULL)
        do
        {
            printf("%d ", p->info);
            p = p->next;
        } while (p != l->first);
    printf("\n");
}

Adaptado de: Celes, W. Estrutura de Dados.

Inserir no início exige fechar o ciclo: o último nó precisa passar a apontar para o nó novo, e só se acha o último percorrendo a lista — O(n). Na lista vazia, o único nó aponta para si mesmo.

03_circular-linkedlist/linkedlist.c

// Function to insert an element at the beginning of the list.
void ll_insert(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode));
    node->info = v;

    if (l->first == NULL) // The only node points to itself.
    {
        node->next = node;
    }
    else
    {
        // Find the last node (the one whose next is the first) to close the cycle.
        ListNode *last = l->first;
        while (last->next != l->first)
            last = last->next;

        node->next = l->first;
        last->next = node;
    }
    l->first = node;
}

Em compensação, mudar o ponto de partida é uma atribuição: first = first->next. Nenhum nó muda de lugar.

Para liberar, quebra-se o ciclo (o nó de partida passa a apontar para NULL) e libera-se como numa lista comum. Sem isso, o laço de liberação nunca encontraria o fim.

// Function to free the memory used by the list.

{

    {

        ListNode *p = l->first->next;
        l->first->next = NULL;

            ListNode *t = p->next; // Store a reference to the next node.

Problema resolvido: o problema de Josephus

Problema. n pessoas em roda; começando pela primeira, conta-se k e a k-ésima sai; a contagem recomeça na seguinte, até sobrar uma. Com 7 pessoas e k = 3, saem 3, 6, 2, 7, 5, 1, e sobra a 4.

Estratégia. Combina as duas operações características da lista circular: andar em volta sem nunca "cair do fim" e retirar um nó conhecendo o anterior. prev começa no último nó, de modo que prev->next é o primeiro; anda-se k − 1 nós, desliga-se prev->next e, como o ciclo continua fechado, a contagem segue do nó seguinte. O cuidado: se o nó retirado era first, first precisa mudar, para não ficar apontando para memória liberada.

03_circular-linkedlist/linkedlist.c

// Function to solve the Josephus problem on the list.
// Combines two operations of the circular list: moving forward around the cycle and
// removing a node knowing the one before it. Counting never "falls off" the end.
int ll_josephus(LinkedList *l, int k)
{
    // prev starts at the last node (the one before first), so that prev->next is the first.
    ListNode *prev = l->first;
    while (prev->next != l->first)
        prev = prev->next;

    while (prev->next != prev) // More than one node left.
    {
        for (int i = 1; i < k; i++) // Move k-1 nodes: prev->next becomes the k-th node.
            prev = prev->next;

        ListNode *victim = prev->next;
        prev->next = victim->next; // Unlink the victim; the cycle stays closed.
        if (victim == l->first)    // Never leave first pointing to freed memory.
            l->first = victim->next;
        printf("%d ", victim->info);
        free(victim);
        // Counting restarts at the node after the victim: prev stays where it is.
    }
    printf("\n");

    l->first = prev; // The survivor is the only node; it points to itself.
    return prev->info;
}

Desvantagens
  • Inserir no início custa O(n), para fechar o ciclo (guardar um ponteiro para o último resolveria).
  • Todo laço precisa de outro critério de parada; esquecer o ponto de partida gera laço infinito.

  • Nada na linguagem distingue uma lista circular de uma comum: o mesmo tipo ListNode serve às duas, e uma função da lista comum aplicada a uma circular nunca encontra NULL.

Listas duplamente encadeadas

Na lista simples, cada nó só conhece o próximo: não dá para andar para trás, e retirar um nó exige ter guardado o anterior durante a busca. A lista duplamente encadeada resolve isso com um ponteiro a mais por nó, prev, para o anterior. A estrutura da lista guarda o primeiro e o último nós e, aqui, também o número de elementos (count), o que torna ll_size O(1).

04_doubly-linkedlist/linkedlist.c

// Define a structure for the linked list.
struct list
{
    int count;       // Number of elements in the linked list.
    ListNode *first; // A pointer to the first node in the linked list.
    ListNode *last;  // A pointer to the last node in the linked list.
};

// Define a structure for a node in the linked list.
struct list_node
{
    int info;       // An integer value stored in the node.
    ListNode *next; // A pointer to the next node in the linked list.
    ListNode *prev; // A pointer to the previous node in the linked list.
};

Toda operação que liga um nó agora acerta dois sentidos. Inserir no início faz o nó novo apontar para o antigo primeiro e, se a lista não estava vazia, faz o antigo primeiro ganhar o nó novo como prev; se estava vazia, o nó novo é também o último. Anexar no fim é o simétrico, usando last — O(1).

04_doubly-linkedlist/linkedlist.c

// Insert an element at the beginning of the linked list.
void ll_insert(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;                                        // Set the 'info' field of the new node to the provided value.
    node->next = l->first;                                 // Make the new node point to the current first node.
    node->prev = NULL;

    if (!ll_is_empty(l))
        l->first->prev = node; // Set the previous of the current first node to the new node.
    else
        l->last = node; // If the list was empty, the new node is also the last node.

    l->first = node; // Update the 'first' pointer to the new node.
    l->count++;      // Increment the count.
}

// Append an element to the end of the linked list.
// With the 'last' pointer, appending costs O(1): no walk is needed.
void ll_append(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode));
    node->info = v;
    node->next = NULL;    // The new node is the last one...
    node->prev = l->last; // ...and comes after the current last (NULL if the list is empty).

    if (l->last != NULL)
        l->last->next = node; // Link the old last node to the new one.
    else
        l->first = node; // Empty list: the new node is also the first one.

    l->last = node;
    l->count++;
}

Retirar fica mais simples de raciocinar: achado o nó p, ele mesmo sabe quem são seus vizinhos. O anterior pula p no sentido next (ou first muda, se p é o primeiro); o seguinte pula p no sentido prev (ou last muda, se p é o último). São quatro casos combinando "é o primeiro?" e "é o último?" — o nó único é os dois ao mesmo tempo.

// Search for a node with a specific value in the linked list.
static ListNode *_search(LinkedList *l, int v)
{
    ListNode *p = l->first;

    while ((p != NULL) && (p->info != v))
        p = p->next;

    return p; // Return the found node or NULL if not found.
}

// Remove the first occurrence of a specific value from the linked list.
void ll_remove(LinkedList *l, int v)
{
    ListNode *p = _search(l, v);

    if (p == NULL)
        return; // If the node is not found, do nothing.

    if (p == l->first)
        l->first = p->next; // If it's the first element, update the 'first'.
    else
        p->prev->next = p->next; // Update the 'next' field of the previous element.

    if (p == l->last)
        l->last = p->prev; // If it's the last element, update the 'last'.
    else
        p->next->prev = p->prev; // Update the 'prev' field of the next element.

    free(p);    // Free the memory used by the removed node.
    l->count--; // Decrement the count.
}

Retirar todas as ocorrências é uma passada só: como o nó conhece o anterior, não é preciso recomeçar do início a cada remoção — basta guardar o próximo antes de liberar. ll_clear libera todos os nós mas mantém a estrutura, que continua utilizável; ll_free libera também a estrutura.

Problema resolvido: inverter a lista no lugar

Problema. Inverter a ordem da lista sem alocar nenhum nó.

Estratégia. Na lista dupla, inverter é trocar os papéis dos dois ponteiros: em cada nó, next e prev trocam de valor; na estrutura, first e last também. O cuidado é com o percurso: depois da troca, o próximo nó a visitar está no antigo next, que foi guardado antes. O(n), e nenhuma alocação.

04_doubly-linkedlist/linkedlist.c

// Reverse the list in place: every node swaps its next and prev; first and last swap too.
void ll_reverse_in_place(LinkedList *l)
{
    ListNode *p = l->first;
    while (p != NULL)
    {
        ListNode *t = p->next; // Save the old next before overwriting it.
        p->next = p->prev;
        p->prev = t;
        p = t; // Continue along the old direction.
    }
    ListNode *t = l->first; // The old first becomes the last, and vice versa.
    l->first = l->last;
    l->last = t;
}

Problema resolvido: separar a lista a partir de uma posição

Problema. Manter os k primeiros nós na lista e mover os demais, na mesma ordem, para uma lista nova, só ajustando ponteiros.

Estratégia. Anda-se até o k-ésimo nó, que será o novo último da lista original. A lista nova começa no seguinte e termina onde a original terminava. Na fronteira, o corte acontece nos dois sentidos: o k-ésimo deixa de apontar para frente (next = NULL) e o primeiro da lista nova deixa de apontar para trás (prev = NULL). Por fim, acertam-se first, last e count das duas listas. Os casos extremos — mover tudo (k ≤ 0) ou nada (k ≥ n) — são tratados antes.

04_doubly-linkedlist/linkedlist.c

// Keep the first k nodes and move the rest to a new list, only adjusting pointers.
LinkedList *ll_split_at(LinkedList *l, int k)
{
    LinkedList *r = ll_create();
    if (k >= l->count) // Nothing to move.
        return r;

    if (k <= 0) // Everything moves: r takes all nodes and l becomes empty.
    {
        r->first = l->first;
        r->last = l->last;
        r->count = l->count;
        l->first = l->last = NULL;
        l->count = 0;
        return r;
    }

    ListNode *p = l->first; // Walk to the k-th node: the new last node of l.
    for (int i = 1; i < k; i++)
        p = p->next;

    r->first = p->next; // The new list starts right after p...
    r->last = l->last;  // ...and ends where l used to end.
    r->count = l->count - k;

    r->first->prev = NULL; // Cut the link in both directions at the border.
    p->next = NULL;
    l->last = p;
    l->count = k;
    return r;
}

Vantagens
  • Anda nos dois sentidos; o anterior de um nó está no próprio nó.
  • Inserir e retirar nas duas pontas em O(1); retirar um nó já encontrado em O(1).
  • Com count, o tamanho é O(1).
Desvantagens
  • Mais memória por elemento: dois ponteiros (16 bytes em 64 bits) em vez de um.
  • Toda operação acerta dois sentidos e mais campos da estrutura: mais pontos para errar.
  • Buscar continua O(n), e não há acesso direto.
Limitações impostas por C
  • A coerência entre next e prev não é verificada por ninguém: um prev esquecido passa despercebido até alguém percorrer a lista de trás para frente.

    {

        if (strcmp(st_cpf(p->info), cpf) == 0)
            _unlink_and_free(l, p);
        p = next;
    }
}

// Remove all students, keeping the (now empty) list structure.
void ll_clear(LinkedList *l)
{
    while (l->first != NULL)
        _unlink_and_free(l, l->first);
}

Problema resolvido: o aluno que vem primeiro na ordem alfabética

Problema. Encontrar o aluno cujo nome vem primeiro em ordem alfabética, devolvendo NULL se a lista estiver vazia.

Estratégia. Percorrer guardando o melhor candidato até agora — mas guardando o nó, não o aluno. A auxiliar static devolve o ListNode *: de posse do nó, quem está dentro do TAD pode continuar o percurso a partir dele, ou desligá-lo da lista. A função pública devolve o aluno, porque quem está fora do TAD não enxerga nós. A comparação é de strings, com strcmp.

// Return the NODE of the student whose name comes first alphabetically (NULL if empty).
// Returning the node (not the student) lets the caller keep walking or unlink from there.
static ListNode *_first_by_name(LinkedList *l)
{
    if (l->first == NULL)
        return NULL;
    ListNode *best = l->first; // Best candidate so far.
    for (ListNode *p = l->first->next; p != NULL; p = p->next)
        if (strcmp(st_name(p->info), st_name(best->info)) < 0)
            best = p;
    return best;
}

// Return the student whose name comes first alphabetically (NULL if the list is empty).
Student *ll_first_by_name(LinkedList *l)
{
    ListNode *node = _first_by_name(l);
    return node == NULL ? NULL : node->info;
}

Ficha: lista de tipos estruturados

Vantagens
  • O nó tem tamanho fixo; o registro pode ser tão grande quanto for preciso.
  • Registro e lista são TADs separados, cada um com suas operações.
Desvantagens
  • Duas alocações por elemento (nó e registro) e mais um nível de ponteiro para chegar aos dados.
  • A lista ainda é de um tipo: para guardar professores, seria outra lista.
Limitações impostas por C
  • Posse de memória não faz parte do tipo: nada no código diz se a lista é dona do registro, e liberar duas vezes (ou nenhuma) só aparece na execução.
  • Strings são vetores de char: comparar e copiar exigem strcmp e strcpy.

Listas heterogêneas

Que problema elas resolvem?

Todas as listas até aqui guardam um único tipo, fixado no código: int, ou Student *. Se o programa precisa de uma lista de alunos e de uma lista de professores, são dois TADs quase idênticos. E se a mesma coleção precisa conter alunos e professores — as pessoas de uma turma, por exemplo —, nenhuma das listas anteriores serve. A lista heterogênea resolve as duas coisas: uma única implementação de lista, cujos nós podem apontar para dados de tipos diferentes.

A solução em C: void * e um identificador de tipo

C não tem tipos genéricos. O recurso disponível é o void *, um ponteiro que pode guardar o endereço de qualquer coisa. Mas, sozinho, um void * não diz o que está do outro lado — e não dá para usar o dado sem saber o tipo. Por isso cada nó guarda, junto do ponteiro, um identificador de tipo (NodeType), e toda operação que precisa ler o dado consulta esse identificador.

// Define a structure for a node in the linked list.
struct list_node
{
    NodeType type;
    void *info;     // Data associated with the node (generic pointer).
    ListNode *prev; // A pointer to the previous node in the linked list.
    ListNode *next; // A pointer to the next node in the linked list.

Acessar por posição mostra o outro lado da moeda. Quem recebe um dado da lista recebe um void * e precisa descobrir o tipo antes de converter o ponteiro; ll_type_at consulta o tipo guardado no nó da posição pedida. Além disso, chegar à posição i custa O(i): na lista não há índice.

// Walk to position pos (0-based). Accessing by position costs O(pos): there is no index.
static ListNode *_at(LinkedList *l, int pos)
{
    if (pos < 0 || pos >= l->count)
        return NULL;
    ListNode *p = l->first;
    for (int i = 0; i < pos; i++)
        p = p->next;
    return p;
}

// Return the type of the record at position pos (pos must be valid).
NodeType ll_type_at(LinkedList *l, int pos)
{
    return _at(l, pos)->type;
}

Quem libera o quê

Os registros são criados fora da lista (em main) e entregues a ela por ll_insert. A decisão deste TAD é que, ao recebê-los, a lista passa a ser dona deles: ll_remove, ll_clear e ll_free liberam também os registros. Já as listas que só apontam para registros de outra lista — como a que ll_professors monta, logo adiante — não podem liberá-los: são liberadas com ll_free_nodes, que solta os nós e a estrutura e deixa os registros intactos.

06_linkedlist-generic/linkedlist.c

// Unlink node p; if free_record is set, also free the record it points to.
static void _unlink(LinkedList *l, ListNode *p, int free_record)
{
    if (p == l->first)
        l->first = p->next;
    else
        p->prev->next = p->next;

    if (p == l->last)
        l->last = p->prev;
    else
        p->next->prev = p->prev;

    if (free_record)
        free(p->info); // Records are flat structs: a single free releases each one.
    free(p);
    l->count--;
}

// Free the nodes and the structure, but not the records (for lists that do not own them).
void ll_free_nodes(LinkedList *l)
{
    while (l->first != NULL)
        _unlink(l, l->first, 0);
    free(l);
}

// Free nodes, structure and records (the list owns its records).
void ll_free(LinkedList *l)
{
    ll_clear(l);
    free(l);
}

Problema resolvido: uma lista só com os professores

Problema. Montar uma lista nova com os professores de uma lista heterogênea, na mesma ordem, apontando para os mesmos registros — sem copiar nenhum professor. Sem professores, o resultado é uma lista vazia, não NULL.

Estratégia. Percorrer a lista original e anexar à nova (em O(1), com last) cada nó cujo tipo é professor, copiando só o ponteiro. A lista nova não é dona dos registros: ela é liberada com ll_free_nodes, e a original continua responsável por eles.

06_linkedlist-generic/linkedlist.c

// New list with only the professors, pointing to the SAME records, in the same order.
// The result is never NULL: with no professor, it is an empty list.
LinkedList *ll_professors(LinkedList *l)
{
    LinkedList *r = ll_create();
    for (ListNode *p = l->first; p != NULL; p = p->next)
        if (p->type == TYPE_PROFESSOR)
            ll_append(r, p->info, p->type); // Same pointer: no record is copied.
    return r;
}

Limitações

  • O compilador não confere o tipo. Inserir um professor marcado como aluno compila sem aviso; o erro aparece na execução, quando o registro é lido com o formato errado.
  • Cada tipo novo mexe na lista. Acrescentar, digamos, técnicos administrativos obriga a alterar o NodeType e todo teste sobre o tipo dentro da lista (imprimir, ler o CPF…). A lista, que deveria ser genérica, conhece todos os tipos que guarda.
  • Posse e liberação ficam por conta de convenção. O void * não diz quem liberará o dado, nem como; a convenção tem de ser documentada e respeitada (aqui: ll_free × ll_free_nodes).
  • Conversões em todo uso. Todo dado que sai da lista volta como void * e precisa de conversão explícita — e uma conversão errada não é detectada.

Uma alternativa, que veremos com mais calma adiante, é a lista não conhecer os tipos de jeito nenhum: quem cria a lista passa a ela as operações sobre os dados — imprimir, comparar, liberar — como ponteiros para funções. A lista chama essas funções sem saber o que elas fazem, e um tipo novo não exige mudar a lista. É o mesmo recurso do qsort da biblioteca padrão, que ordena qualquer vetor recebendo a função de comparação.

// Function to create an empty linked list and return a pointer to it.
LinkedList *ll_create()
{
    LinkedList *l = (LinkedList *)malloc(sizeof(LinkedList)); // Allocate memory for the list structure.
    l->first = NULL;                                          // Initialize the 'first' pointer to NULL, indicating an empty list.
    return l;                                                 // Return a pointer to the newly created list.
}

// Function to check whether the linked list is empty.
int ll_is_empty(LinkedList *l)
{
    return l->first == NULL; // Check if the 'first' pointer is NULL, indicating an empty list.
}

// Function to insert an element at the beginning of the linked list.
void ll_insert(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;                                        // Set the 'info' field of the new node to the provided value.
    node->next = l->first;                                 // Make the new node point to the current first node.
    l->first = node;                                       // Update the 'first' pointer to point to the new node.
}

// Function to insert an element while keeping the list in ascending order.
void ll_insert_sorted(LinkedList *l, int v)
{
    ListNode *prev = NULL;  // Node that will precede the new one.
    ListNode *p = l->first; // Node used to walk the list.

    // Find the insertion point: first node whose value is not smaller than v.
    while (p != NULL && p->info < v)
    {
        prev = p;
        p = p->next;
    }

    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;

    if (prev == NULL) // Insert at the beginning (empty list or v is the smallest).
    {
        node->next = l->first;
        l->first = node;
    }
    else // Insert in the middle or at the end, right after 'prev'.
    {
        node->next = prev->next;
        prev->next = node;
    }
}

// Function to get the size (number of elements) of the linked list.
int ll_size(LinkedList *l)
{
    int cnt = 0; // Initialize a counter to zero.
    for (ListNode *p = l->first; p != NULL; p = p->next)
    {
        cnt++; // Increment the counter for each node in the list.
    }
    return cnt; // Return the total number of elements in the linked list.
}

// Function to verify if a value is in the list
int ll_is_in(LinkedList *l, int v)
{
    ListNode *p = l->first;
    while (p != NULL)
    {
        if (p->info == v)
            return 1;
        p = p->next;
    }
    return 0;
}

// Function to remove the first occurrence of a specific element from the linked list
int ll_remove(LinkedList *l, int v)
{
    ListNode *p = l->first; // Pointer to the current node being examined
    ListNode *prev = NULL;  // Pointer to the previous node

    // Traverse the list
    while (p != NULL)
    {
        // Check if the current node contains the element to be removed
        if (p->info == v)
        {
            // If the element to be removed is at the beginning of the list
            if (prev == NULL)
                l->first = p->next; // Update the 'first' pointer to skip the first node
            // If the element to be removed is in the middle or end of the list
            else
                prev->next = p->next; // Update the 'next' pointer of the previous node

            free(p);  // Deallocate memory occupied by the removed node
            return 1; // Indicate success (element found and removed)
        }
        else
        {
            prev = p;    // Update the 'prev' pointer
            p = p->next; // Move to the next node
        }
    }

    return 0; // Indicate that the element was not found
}

// Remove all elements that match a specific value from the linked list
void ll_remove_all(LinkedList *l, int v)
{
    while (ll_remove(l, v))
        ;
}

// Function to append an element to the end of the linked list.
// Without a pointer to the last node, the whole list must be walked: cost grows with n.
void ll_append(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;
    node->next = NULL; // The new node will be the last one.

    if (l->first == NULL) // Empty list: the new node is also the first one.
    {
        l->first = node;
        return;
    }

    ListNode *p = l->first;
    while (p->next != NULL) // Stop at the current last node.
        p = p->next;
    p->next = node; // Link the old last node to the new one.
}

// Function to build a new list with the n values of array v, in the same order.
LinkedList *ll_from_array(int v[], int n)
{
    LinkedList *l = ll_create();
    ListNode *last = NULL; // Last node built so far: appending after it costs O(1).
    for (int i = 0; i < n; i++)
    {
        ListNode *node = (ListNode *)malloc(sizeof(ListNode));
        node->info = v[i];
        node->next = NULL;
        if (last == NULL)
            l->first = node; // The first value starts the list.
        else
            last->next = node;
        last = node;
    }
    return l;
}

// Function to remove repeated values, keeping only the first occurrence of each one.
// For each node, a second walk (q, with its own prev) removes the later copies of the same value.
void ll_remove_duplicates(LinkedList *l)
{
    for (ListNode *p = l->first; p != NULL; p = p->next)
    {
        ListNode *prev = p;    // The node before q; starts at p itself.
        ListNode *q = p->next; // Walks the rest of the list looking for copies of p->info.
        while (q != NULL)
        {
            if (q->info == p->info)
            {
                prev->next = q->next; // Skip the copy...
                free(q);              // ...and free it.
                q = prev->next;       // prev stays where it is.
            }
            else
            {
                prev = q;
                q = q->next;
            }
        }
    }
}

// Function to free the memory used by the linked list.
void ll_free(LinkedList *l)
{
    ListNode *p = l->first;
    while (p != NULL)
    {
        ListNode *t = p->next; // Store a reference to the next node.
        free(p);               // Free the memory allocated for the current node.
        p = t;                 // Move to the next node.
    }
    free(l); // Free the memory allocated for the list structure itself.
}

// Function to display all elements of the linked list.
void ll_print(LinkedList *l)
{
    for (ListNode *p = l->first; p != NULL; p = p->next)
    {
        printf("%d ", p->info); // Print the 'info' field of each node.
    }
    printf("\n"); // Print a newline character to separate the output.
}

struct list
{

    ListNode *last;  // A pointer to the last node (NULL if the list is empty).

// Define a structure for a node in the linked list.
struct list_node
{

    ListNode *next; // A pointer to the next node in the linked list.
};

// Function to create an empty linked list: both ends are NULL.
LinkedList *ll_create()
{
    LinkedList *l = (LinkedList *)malloc(sizeof(LinkedList));
    l->first = NULL;
    l->last = NULL;
    return l;
}

// Function to check whether the linked list is empty.
int ll_is_empty(LinkedList *l)
{
    return l->first == NULL;
}

// Function to insert an element at the beginning of the linked list.
void ll_insert(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode));
    node->info = v;
    node->next = l->first;
    if (l->first == NULL) // Empty list: the new node is also the last one.
        l->last = node;
    l->first = node;
}

// Function to append an element to the end: no walk, thanks to 'last'.
void ll_append(LinkedList *l, int v)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode));
    node->info = v;
    node->next = NULL;
    if (l->last == NULL) // Empty list: the new node is first AND last.
        l->first = node;
    else
        l->last->next = node; // Link after the current last node.
    l->last = node;
}

// Function to remove the first occurrence of v.
// Same walk as in 01_linkedlist, plus one extra care: removing the last node moves 'last'.
int ll_remove(LinkedList *l, int v)
{
    ListNode *prev = NULL;
    ListNode *p = l->first;
    while (p != NULL && p->info != v)
    {
        prev = p;
        p = p->next;
    }
    if (p == NULL) // Not found.
        return 0;

    if (prev == NULL)
        l->first = p->next; // Removing the first node.
    else
        prev->next = p->next;

    if (p == l->last)
        l->last = prev; // The node before it becomes the last (NULL if the list emptied).

    free(p);
    return 1;
}

// Function to move every node of l2 to the end of l1, only adjusting pointers.
void ll_join(LinkedList *l1, LinkedList *l2)
{
    if (l2->first == NULL) // Nothing to move.
        return;

    if (l1->first == NULL) // l1 empty: it simply takes l2's chain.
        l1->first = l2->first;
    else
        l1->last->next = l2->first; // Hook l2's chain after l1's last node.
    l1->last = l2->last;

    l2->first = l2->last = NULL; // l2 no longer owns those nodes.
}

// Function to merge two ascending lists into a new one, moving their nodes.
LinkedList *ll_merge_sorted(LinkedList *a, LinkedList *b)
{
    LinkedList *r = ll_create();
    while (a->first != NULL || b->first != NULL)
    {
        LinkedList *from; // The list whose first node is the smallest.
        if (b->first == NULL || (a->first != NULL && a->first->info <= b->first->info))
            from = a;
        else
            from = b;

        ListNode *node = from->first; // Unlink the first node of 'from'...
        from->first = node->next;
        if (from->first == NULL)
            from->last = NULL;

        node->next = NULL; // ...and append it to r (O(1) with 'last').
        if (r->last == NULL)
            r->first = node;
        else
            r->last->next = node;
        r->last = node;
    }
    return r;
}

// Function to free the memory used by the linked list.
void ll_free(LinkedList *l)
{
    ListNode *p = l->first;
    while (p != NULL)
    {
        ListNode *t = p->next; // Store a reference to the next node.
        free(p);
        p = t;
    }
    free(l);
}

// Function to display all elements of the linked list.
void ll_print(LinkedList *l)
{
    for (ListNode *p = l->first; p != NULL; p = p->next)
        printf("%d ", p->info);
    printf("\n");
}

{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode));
    node->info = v;

    if (l->first == NULL) // The only node points to itself.
    {
        node->next = node;
    }
    else

        ListNode *last = l->first;
        while (last->next != l->first)
            last = last->next;

        node->next = l->first;
        last->next = node;
    }
    l->first = node;
}

            p = p->next;

}

        l->first = l->first->next;
}

// Function to solve the Josephus problem on the list.
// Combines two operations of the circular list: moving forward around the cycle and
// removing a node knowing the one before it. Counting never "falls off" the end.
int ll_josephus(LinkedList *l, int k)
{
    // prev starts at the last node (the one before first), so that prev->next is the first.
    ListNode *prev = l->first;
    while (prev->next != l->first)
        prev = prev->next;

    while (prev->next != prev) // More than one node left.
    {
        for (int i = 1; i < k; i++) // Move k-1 nodes: prev->next becomes the k-th node.
            prev = prev->next;

        ListNode *victim = prev->next;
        prev->next = victim->next; // Unlink the victim; the cycle stays closed.
        if (victim == l->first)    // Never leave first pointing to freed memory.
            l->first = victim->next;
        printf("%d ", victim->info);
        free(victim);
        // Counting restarts at the node after the victim: prev stays where it is.
    }
    printf("\n");

    l->first = prev; // The survivor is the only node; it points to itself.
    return prev->info;
}

// Function to free the memory used by the list.
void ll_free(LinkedList *l)
{
    if (l->first != NULL)
    {
        // Break the cycle, so the list ends in NULL like a regular one.
        ListNode *p = l->first->next;
        l->first->next = NULL;
        while (p != NULL)
        {
            ListNode *t = p->next; // Store a reference to the next node.
            free(p);
            p = t;
        }
    }
    free(l);
}

{

    if (p != NULL)
        do
        {
            printf("%d ", p->info);
            p = p->next;
        } while (p != l->first);
    printf("\n");
}

    l->first = NULL;                                          // Initialize the 'first' pointer to NULL, indicating an empty list.

{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode)); // Allocate memory for a new node.
    node->info = v;                                        // Set the 'info' field of the new node to the provided value.
    node->next = l->first;                                 // Make the new node point to the current first node.
    node->prev = NULL;

        l->first->prev = node; // Set the previous of the current first node to the new node.
    else

    l->count++;      // Increment the count.
}

{

    while ((p != NULL) && (p->info != v))
        p = p->next;

    return p; // Return the found node or NULL if not found.
}

int ll_is_in(LinkedList *l, int v)
{

}

// Remove the first occurrence of a specific value from the linked list.
void ll_remove(LinkedList *l, int v)
{
    ListNode *p = _search(l, v);

    if (p == NULL)
        return; // If the node is not found, do nothing.

    if (p == l->first)
        l->first = p->next; // If it's the first element, update the 'first'.
    else
        p->prev->next = p->next; // Update the 'next' field of the previous element.

    if (p == l->last)
        l->last = p->prev; // If it's the last element, update the 'last'.
    else
        p->next->prev = p->prev; // Update the 'prev' field of the next element.

    free(p);    // Free the memory used by the removed node.
    l->count--; // Decrement the count.
}

    node->prev = l->last; // ...and comes after the current last (NULL if the list is empty).

    else

{

    {
        ListNode *next = p->next; // Save it: p may be freed below.
        if (p->info == v)
        {
            if (p == l->first)
                l->first = p->next;
            else
                p->prev->next = p->next;

            if (p == l->last)
                l->last = p->prev;
            else
                p->next->prev = p->prev;

}

// Reverse the list in place: every node swaps its next and prev; first and last swap too.
void ll_reverse_in_place(LinkedList *l)
{
    ListNode *p = l->first;
    while (p != NULL)
    {
        ListNode *t = p->next; // Save the old next before overwriting it.
        p->next = p->prev;
        p->prev = t;
        p = t; // Continue along the old direction.
    }
    ListNode *t = l->first; // The old first becomes the last, and vice versa.
    l->first = l->last;
    l->last = t;
}

// Keep the first k nodes and move the rest to a new list, only adjusting pointers.
LinkedList *ll_split_at(LinkedList *l, int k)
{
    LinkedList *r = ll_create();
    if (k >= l->count) // Nothing to move.
        return r;

    if (k <= 0) // Everything moves: r takes all nodes and l becomes empty.
    {
        r->first = l->first;
        r->last = l->last;
        r->count = l->count;
        l->first = l->last = NULL;
        l->count = 0;
        return r;
    }

    ListNode *p = l->first; // Walk to the k-th node: the new last node of l.
    for (int i = 1; i < k; i++)
        p = p->next;

    r->first = p->next; // The new list starts right after p...
    r->last = l->last;  // ...and ends where l used to end.
    r->count = l->count - k;

    r->first->prev = NULL; // Cut the link in both directions at the border.
    p->next = NULL;
    l->last = p;
    l->count = k;
    return r;
}

}

{

        l->first = p->next;
    else
        p->prev->next = p->next;

        l->last = p->prev;
    else
        p->next->prev = p->prev;

}

    node->info = info;
    node->next = l->first;
    node->prev = NULL;

    node->info = info;

// Unlink node p; if free_record is set, also free the record it points to.
static void _unlink(LinkedList *l, ListNode *p, int free_record)
{
    if (p == l->first)
        l->first = p->next;
    else
        p->prev->next = p->next;

    if (p == l->last)
        l->last = p->prev;
    else
        p->next->prev = p->prev;

    if (free_record)
        free(p->info); // Records are flat structs: a single free releases each one.
    free(p);
    l->count--;
}

        _unlink(l, l->first, 1);
}

// Walk to position pos (0-based). Accessing by position costs O(pos): there is no index.
static ListNode *_at(LinkedList *l, int pos)
{
    if (pos < 0 || pos >= l->count)
        return NULL;
    ListNode *p = l->first;
    for (int i = 0; i < pos; i++)
        p = p->next;
    return p;
}

// Return the type of the record at position pos (pos must be valid).
NodeType ll_type_at(LinkedList *l, int pos)
{
    return _at(l, pos)->type;
}

// New list with only the professors, pointing to the SAME records, in the same order.
// The result is never NULL: with no professor, it is an empty list.
LinkedList *ll_professors(LinkedList *l)
{
    LinkedList *r = ll_create();
    for (ListNode *p = l->first; p != NULL; p = p->next)
        if (p->type == TYPE_PROFESSOR)
            ll_append(r, p->info, p->type); // Same pointer: no record is copied.
    return r;
}

// Free the nodes and the structure, but not the records (for lists that do not own them).
void ll_free_nodes(LinkedList *l)
{
    while (l->first != NULL)
        _unlink(l, l->first, 0);
    free(l);
}

// Free nodes, structure and records (the list owns its records).
void ll_free(LinkedList *l)
{
    ll_clear(l);
    free(l);
}

   char cpf_block2[4];
   char cpf_block3[4];
   char cpf_block4[3];

   // Parse the CPF into four blocks.
   sscanf(p->cpf, "%3s", cpf_block1);
   sscanf(p->cpf + 3, "%3s", cpf_block2);
   sscanf(p->cpf + 6, "%3s", cpf_block3);
